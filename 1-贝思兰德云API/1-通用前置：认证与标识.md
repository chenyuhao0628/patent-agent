# 第一部分 通用前置：认证与标识

## 1.1 使用本机 Token

密码不要放入命令、聊天、URL 或 JSON。密码只在本机隐藏输入，登录后只使用已经安全保存的 Token 文件；不要开启 `set -x`。

**首次获取 Token**（只需执行一次，后续复用）：

```bash
umask 077                                  # 保证新建文件只有本人可读
read -rsp '请输入贝思兰德密码: ' PW; echo
TOKEN=$(curl -sS -k -X POST "$API/Auth/GetToken" \
  -H 'Content-Type: application/json' \
  -d "{\"UserName\":\"<账号>\",\"Password\":\"$PW\"}" \
  | python3 -c 'import json,sys; print(json.load(sys.stdin)["Data"]["Token"])')
unset PW
test -n "$TOKEN" && printf '%s' "$TOKEN" > /tmp/baseland_token && chmod 600 /tmp/baseland_token
echo "Token 已保存（${#TOKEN} 字符）"
```

**每次会话开始**：

```bash
TOKEN_FILE='/tmp/baseland_token'
test -r "$TOKEN_FILE" || { echo '缺少 Token 文件，先按上面的步骤生成'; exit 1; }
TOKEN=$(<"$TOKEN_FILE")
API='https://cloudapi02.baselandtec.com/v1'
ORIGIN='https://cqgd.baselandtec.com'
```

Token 失效时会返回 `401` 或 `IsSuccess=false`，重新执行首次获取步骤即可。

## 1.2 四个关键 ID

贝思兰德有四级标识，**用错层级是最常见的报错原因**。这些 ID 都从接口返回获取，不要自己拼：

| ID | 含义 | 从哪来 | 用在哪 |
| --- | --- | --- | --- |
| `CaseId` | 案件 ID | 案件列表行 | 案件级查询 |
| `CaseProcId` | **流程实例** ID | 案件列表行 | 流程级查询、文件下载、流转记录 |
| `CaseHandId` | **递交实例** ID | 案件列表行（**仅递交中的行有值**）、`GetHandInfo` | 表单保存、上传、内部转交 |
| `ProcId` | **流程模板** ID | `GetCaseDetailProcList` 返回 | 年费期限计算 |

```bash
CASE_NO='填写目标案号'
CASE_ID='填写列表行返回的 CaseId'
CASE_PROC_ID='填写列表行返回的 CaseProcId'
CASE_HAND_ID='填写列表行返回的 CaseHandId'   # 仅递交中案件有
PROC_ID='填写 GetCaseDetailProcList 返回的 ProcId'
```

> **`CaseHandId` 只有已创建递交实例的案件才有。** 待办案件的行里该字段为空，此时 `IsExistHandInfo` 也返回 `false`——需要先按 3.2 调用 `StartHand` 创建递交实例，再重新查询列表取得。

## 1.3 请求与响应约定

请求头（除 `GetToken` 外都需要）：

```http
Authorization: <Token>
Origin: https://cqgd.baselandtec.com
Referer: https://cqgd.baselandtec.com/login.html
Language: zh-CN
Content-Type: application/json
```

响应统一为：

```json
{ "Data": ..., "IsSuccess": true, "Code": 0, "Message": null, "Ext": null }
```

**判断成功要看 `IsSuccess`，不要只看 HTTP 200。** 服务端在业务失败时同样返回 HTTP 200。两类常见失败：

| `Message` | 含义 | 处理 |
| --- | --- | --- |
| `无访问权限` | 该账号未被授权调用此接口 | 不要反复重试，见附录 A |
| `系统错误: e` | 服务端异常，通常是请求体缺必填字段 | 核对本文给出的参数结构 |
