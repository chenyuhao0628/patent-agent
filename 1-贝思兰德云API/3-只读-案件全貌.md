## 2.4 案件全貌

> **前置**：需要 `$CASE_ID`（案件级查询）与 `$CASE_PROC_ID`（流程详情）。两个 ID 都从 2.1 的列表行取得。

```bash
# 案件信息总览（开卷/商务备注、业务部门、委托类型、家族号）
curl -sS -k --get "$API/CaseInfo/GetUpdateCaseInfo" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseId=$CASE_ID"

# 流程详情（官文备注、处理备忘、派发人）
curl -sS -k --get "$API/CaseInfo/GetCaseProcById" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseProcId=$CASE_PROC_ID"
```

核心返回字段：

| 字段 | 含义 |
| --- | --- |
| `Data.CaseInfo.Remark` | 开卷 / 商务备注 |
| `Data.CaseInfo.BusinessUserName` | 业务部门 |
| `Data.CaseInfo.ClientEntrustTypeName` | 委托类型 |
| `Data.CaseInfo.CaseFamilyNo` | 专利家族编号 |
| `Data.CaseProc.OfficeNote` | 官文备注 |
| `Data.CaseProc.ProcNote` | 处理备忘 |
| `Data.CaseProc.CreateUserName` | 流程派发人 |

### 案件流程明细（信息量最大的单个接口）

```bash
curl -sS -k -X POST "$API/CaseInfo/GetCaseDetailProcList" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  -H 'Content-Type: application/json' \
  -d '{
    "caseId": "'"$CASE_ID"'",
    "TableType": 80001,
    "SortInfo": {},
    "UserTableTitleColumnList": [
      "CaseProcName", "CaseProcCustomDate", "CaseProcLegalDate",
      "CaseProcClientDate", "CaseProcFinishDate", "CaseProcUndertakerUserName"
    ]
  }'
```

**这个接口按 `UserTableTitleColumnList` 决定返回哪些列，缺这两个字段服务端会直接报 `系统错误: e`。** 只传 `caseId` 是不够的。

返回案件下全部流程，每条含约 160 个字段，其中使用频率最高的：

| 字段 | 含义 |
| --- | --- |
| `CaseProcLegalDate` / `CaseProcCustomDate` | **法定期限 / 内部期限**（剩余天数由此计算，见下文） |
| `ProcProcessingDays` | 流程处理天数 |
| `CaseProcOfficeFeeTotal` / `CaseProcServiceFeeTotal` / `CaseProcOfficeAndServiceFeeTotal` | 官费 / 服务费 / 合计 |
| `CaseProcNumberResponses` | 答复次数 |
| `CaseProcClientDate` / `CaseProcFinishDate` / `CaseProcCreateDate` | 客户期限 / 完结 / 创建日期 |
| `IsCanStartHand` / `IsCanDelete` / `IsExistsHand` / `IsChangeUndertaker` | 操作权限标志位 |
| `StatusCode` / `CaseProcCurrentStatus` | 流程状态码与文本 |
| `ChildCaseProcList` / `ChildCaseProcCount` | 子流程（国别、分案等） |
| `ProcId` | **流程模板 ID**，年费期限计算要用它 |

加 `"IsQueryUnFinish": true` 可只查未完结流程。

#### 计算剩余天数

期限不由接口直接给出天数，需要按 `CaseProcLegalDate`（法定期限）和 `CaseProcCustomDate`（内部期限）自行计算：**取两者中较早的一个，减今天**。负数表示已逾期。

```python
from datetime import datetime, date

def days_left(row):
    """返回剩余天数；负数表示已逾期。"""
    vals = []
    for key in ('CaseProcLegalDate', 'CaseProcCustomDate'):
        raw = row.get(key)
        if raw:
            try:
                vals.append(datetime.strptime(str(raw)[:10], '%Y-%m-%d').date())
            except ValueError:
                pass
    return (min(vals) - date.today()).days if vals else None
```

据此可分档：已逾期 / ≤3 天 / 4–7 天 / 8–30 天 / >30 天。
