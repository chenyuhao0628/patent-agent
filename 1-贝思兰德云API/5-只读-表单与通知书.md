## 2.6 递交实例与官方表单

> **前置**：需要 `$CASE_HAND_ID`。该 ID 只出现在**递交中**案件的列表行，或用 `GetHandInfo` 从 `Data.HandInfo.CaseHandId` 取得（见 2.5）。

```bash
# 官方表单清单：fileType=0 申请原文区，fileType=2 中间文件区
curl -sS -k --get "$API/CaseInfo/GetOfficialFormList" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode 'fileType=2' \
  --data-urlencode "caseHandId=$CASE_HAND_ID"
```

返回表单清单，`IsSelect` 标出**哪些表单已在该递交实例中选中**：

```json
[{"FormName": "意见陈述书", "Code": 100012, "IsSelect": true}, ...]
```

**不要根据专利名称自行拼表单代码**，一律以本接口返回的 `Code` 为准。

### 三个专用表单的读取

```bash
# 请求书（提出申请路线）
curl -sS -k --get "$API/CaseInfo/GetFormPatentRequestInfo" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID"

# 意见陈述书（答复审查意见路线）
curl -sS -k --get "$API/CaseInfo/GetFormOpinionStatement" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID"

# 补正书（补正路线）
curl -sS -k --get "$API/CaseInfo/GetFormCorrection" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID"
```

未创建过的表单返回 `Data=null`，属正常，不代表出错。

### 递交实例文件

```bash
curl -sS -k --get "$API/CaseInfo/GetCaseHandFileList" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID"
```

## 2.7 通知书与文件下载

> **前置**：通知书三字段需要 `$CASE_HAND_ID`；下载流程文件需要 `$CASE_PROC_ID`。

### 取通知书三字段

```bash
curl -sS -k --get "$API/CaseInfo/GetCaseHandProcRelateNoticeInfo" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID"
```

返回：

```json
{
  "NoticeId": "...",
  "PostDate": "2026-08-12T00:00:00",
  "NoticeName": "第一次审查意见通知书",
  "FaWenXLH": "2026080701800270"
}
```

字段映射（补正与答复审查意见两条路线都要用）：

```text
PostDate   → NoticeDate
NoticeName → NoticeName
FaWenXLH   → NoticeNo
```

### 下载流程文件

```bash
PROC_FILES_JSON='/tmp/baseland_case_proc_files.json'

curl -sS -k --get "$API/CaseInfo/GetCaseProcFileList" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseProcId=$CASE_PROC_ID" \
  -o "$PROC_FILES_JSON"

python3 - "$PROC_FILES_JSON" <<'PY'
import json, sys
data = json.load(open(sys.argv[1], encoding='utf-8'))
for item in data.get('Data') or []:
    name = item.get('FileName') or ''
    if name.lower().endswith('.pdf'):
        print(item.get('FileNo', ''), '\t', name)
PY
```

下载并校验：

```bash
PDF_DIR='./通知书PDF'
PDF_FILE_NO='从文件列表中选择'
PDF_NAME='通知书.pdf'
mkdir -p "$PDF_DIR"

curl -sS -k --get "$API/NoPermissionRequired/FileStorageGetFile" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "fileNo=$PDF_FILE_NO" \
  --data-urlencode 'forBlob=true' \
  -o "$PDF_DIR/$PDF_NAME"

if [ "$(dd if="$PDF_DIR/$PDF_NAME" bs=1 count=5 2>/dev/null)" = '%PDF-' ]; then
  echo "PDF 校验通过：$PDF_DIR/$PDF_NAME"
else
  echo '下载内容不是有效 PDF，停止后续处理'
  exit 1
fi
```

> 从上一步选择实际的 `FileNo`，不要根据文件名猜编号。递交实例产生的文件同样先用 `GetCaseHandFileList` 取得 `FileNo` 再下载；**不要假定列表中的每个文件都是 PDF**。

## 2.8 官文清单与官文详情

> **前置**：`$CASE_ID`；按 `noticeId` 查时需要 `$NOTICE_ID`（可从下文的官文清单、或案件新动态明细行取得，见 [15-只读-授权与获证检测.md](./15-只读-授权与获证检测.md)）。

### 列某案的全部官文

```bash
curl -sS -k -X POST "$API/CaseInfo/GetNoticeListByCaseId" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' -H 'Content-Type: application/json' \
  -d "{\"caseId\":\"$CASE_ID\",\"PagedInfo\":{\"PageIndex\":1,\"PageSize\":100}}"
```

条数：`GET /CaseInfo/GetNoticeListByCaseIdCount?caseId=$CASE_ID`。

每行关键字段：`NoticeId`、`NoticeName`、`NoticeTypeCode`、`PostDate`、`NoticeStatus` / `NoticeStatusName`、`IsRead`、`IsUserDownloaded`、`TransferStatusName`、`FileList`、`CaseProcName`（该官文挂在哪个流程上，未挂的为空）。

**实测样例（一个已授权的发明）**：共 8 条，`PostDate` 倒序——办理登记手续通知书(09-14) → 电子申请回执 ×3 → 第一次审查意见通知书 → 进入实质审查阶段通知书 → 公布通知书 → 初步审查合格通知书。

### 取单个官文详情

```bash
curl -sS -k --get "$API/CaseInfo/GetNoticeById" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "noticeId=$NOTICE_ID"
```

返回 `{Case, Notice, NoticeExtend, FileList, NoticeFeeList, NoticeAnnualLateFeeList}`：

| 组 | 说明 |
| --- | --- |
| `Notice` | `NoticeName`、`NoticeTypeCode`、`NoticeNumber`、`PostDate`、`DownloadDate`、`NoticeStatus`/`NoticeStatusName`、`Volume` |
| `NoticeExtend` | `FaWenXLH`、`CPCAnJuanBBH`、`CPCAnJuanH`、`FaMingMC`、**`DaFuRQ`**（该官文的办理/答复期限） |
| `FileList` | 每项含 `FileNo` + `FileName`（通常是同名 `.pdf` 与 `.zip` 各一份）→ 用 `FileNo` 走 2.7 的下载 |
| `NoticeFeeList` | `FeeName` / `FeeAmount` / 币种（如年费） |

### 官文状态字典

```bash
curl -sS -k "$API/SystemTypeSetting/GetNoticeStatusType" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN'
```

| 值 | 含义 |
| --- | --- |
| 99 | 无需导入 |
| 200 | 待导入（已在官文库、未进案卷） |
| 300 | 已导入 |
| 400 | 异常官文 |
| 500 | 未关联案件 |

> **`待导入` 是重要分界**：此时官文能查到、附件能下载，但**案件文件中心与案件流程里还没有**（实测一例：办登通知书 `待导入`、案件文件中心无该文件、案件流程无办登节点）。判断「官文到没到」用本节的官文清单；判断「有没有进案卷」用 [3-只读-案件全貌.md](./3-只读-案件全貌.md) 的全案文件清单（`GetCaseFileAllList`）。

### 全局官文管理列表的权限

`POST /CaseInfo/GetNoticeList`、`GET /CaseInfo/GetNoticeListTabCount`、`GET /CaseInfo/GetNoticeListChildTabCount` 实测返回 `无访问权限`（本账号未开通官文管理模块）。注意 `TabCount` 会带回**全零占位对象**而 `IsSuccess=false`，**不要当成「没有官文」**。
