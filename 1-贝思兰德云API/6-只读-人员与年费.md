## 2.8 申请人与发明人检索

> **前置**：已完成 1.1 的 Token 设置。无需 ID。

```bash
SEARCH_KEY='<姓名或公司名关键词，留空表示不过滤>'

curl -sS -k --get "$API/CaseInfo/GetApplicantListQueryCase" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "SearchValue=$SEARCH_KEY" \
  --data-urlencode 'PageIndex=1' \
  --data-urlencode 'PageSize=20'

curl -sS -k --get "$API/CaseInfo/GetInventorListByQueryCase" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "SearchValue=$SEARCH_KEY" \
  --data-urlencode 'PageIndex=1' \
  --data-urlencode 'PageSize=20'
```

`SearchValue` 传空字符串表示不过滤，返回全部（分页）。

> ⚠️ **`GetInventorListByQueryCase` 返回中包含 `IdCard`（身份证号）。** 命令行使用时不要把结果写入日志、聊天记录或可共享的文件；如需展示，先屏蔽该字段。

## 2.9 年费

> **前置**：汇总接口无需 ID；期限计算需要 `$CASE_ID` 与 `$PROC_ID`（`$PROC_ID` 从 2.4 的 `GetCaseDetailProcList` 返回取得）。

### 汇总

```bash
# 年费页签计数：WaitPayCount 为待缴件数
curl -sS -k --get "$API/AnnuaFeeMonitoring/GetAnnuaFeeMonitoringTabCount" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN'

# 年费金额汇总
curl -sS -k -X POST "$API/AnnuaFeeMonitoring/GetAnnuaFeeMonitoringsStatisticsList" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  -H 'Content-Type: application/json' \
  -d '{"PagedInfo":{"pageIndex":1,"pageSize":50}}'
```

`GetAnnuaFeeMonitoringTabCount` 返回 `{WaitPayCount, ConfirmPaidCount, PayingCount, PaidCount, PendingCount, InApprovalCount, AbnormalCount}`。

金额汇总返回 `[{OfficialFeePayTypeName, CurrencyName, Amount}]`。

### 期限计算

```bash
curl -sS -k --get "$API/CaseInfo/ProcCaculateNextYearLegalDate" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseId=$CASE_ID" \
  --data-urlencode "procId=$PROC_ID" \
  --data-urlencode "annualFeeYearTo=2026"
```

> **`procId` 使用 `GetCaseDetailProcList` 返回的 `ProcId`（流程模板 ID）**，不是 `CaseProcId`。
>
> 不涉及年费的流程返回 `Data=null`，属正常。
>
> 年费明细列表需要额外权限，见附录 A。

## 2.11 申请法定期限计算

根据申请类型、国家、优先权与 PCT 信息，算出该申请应当适用的法定期限基准日。

```bash
curl -sS -k -X POST "$API/ApplyCase/GetLegalDate" \
  -H "Authorization: $TOKEN" -H 'Origin: $ORIGIN' \
  -H 'Language: zh-CN' -H 'Content-Type: application/json' \
  -d '{
    "countryCode": 36,
    "caseRelatedTypeId": "<案件关联类型 ID>",
    "applyTypeCode": 2,
    "PriorityDateList": [],
    "PctApplicationDate": null
  }'
```

| 字段 | 来源 | 说明 |
| --- | --- | --- |
| `countryCode` | 案件列表行的 `CountryCode` | `36` = 中国 |
| `caseRelatedTypeId` | 案件列表行的 `CaseRelationTypeId` | 案件关联类型 |
| `applyTypeCode` | 案件列表行的 `ApplyTypeCode` | 申请类型代码 |
| `PriorityDateList` | 优先权列表的 `PriorityDate` | 数组，无优先权传 `[]` |
| `PctApplicationDate` | PCT 信息的 `PctApplicationDate` | 非 PCT 传 `null` |

返回计算出的法定期限日期（字符串）。**当输入不足以判定期限时返回 `null`**，属正常。

> **与 2.9「年费期限计算」的区别**：本节算的是**申请阶段**的法定期限基准日（提出申请、请求快速预审用）；2.9 的 `ProcCaculateNextYearLegalDate` 算的是**年费缴纳年度**对应的期限。两者输入参数不同——本节用 `countryCode`/`applyTypeCode`，2.9 用 `caseId`/`procId`。
