## 3.1 先识别路线，不按专利名称猜

先从案件的 `CaseProcName`、`CaseProcNameInfo` 和 `GetOfficialFormList` 返回值识别业务路线，再决定表单和文件接口。

| 业务路线 | 关键表单 | 表单保存对象 | 文件/文字特点 | 专用验收接口 |
| --- | --- | --- | --- | --- |
| 提出申请 | 发明 `110101`；实用新型 `120101` | `DivisionalCase`、`RequestInfo`、`SpecificationInfo` | 若页面显示申请原文卡片，使用"五书 + 原始混合文件"路线 | `GetFormPatentRequestInfo` |
| 补正 | `100006` 补正书 | `Correction` + `CorrectionContentList` | 核心是逐条填写补正内容，不是上传一份补正书文件 | `GetFormCorrection` |
| 答复审查意见 | `100012` 意见陈述书 | `OpinionStatement` + `File` | 先关联通知书，再上传 Word 答复文件 | `GetFormOpinionStatement` |

## 3.2 取得当前递交实例

只有案件确实处于 `waitHand`、且业务上已经决定启动递交实例时，才使用下面的状态变更接口。启动后必须重新查询，不能继续使用旧的 `CaseHandId`。

```bash
curl -sS -k --get "$API/CaseInfo/StartHand" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseProcId=$CASE_PROC_ID"
```

## 3.3 读取页面实际提供的表单

选中普通表单的通用步骤是：先 `IsHasCaseHandForm`，只有返回 `false` 时才调用 `AddCaseHandForm`。

```bash
curl -sS -k --get "$API/CaseInfo/IsHasCaseHandForm" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID" \
  --data-urlencode 'formCode=<FormCode>'

# 仅在上一步返回 false 时调用
curl -sS -k --get "$API/CaseInfo/AddCaseHandForm" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID" \
  --data-urlencode 'formCode=<FormCode>'
```

`FormCode` 一律取自 `GetOfficialFormList` 的返回，不要用案件名称替代。

## 3.4 提出申请路线

### 读取并填写请求书结构化数据

```bash
curl -sS -k --get "$API/CaseInfo/GetFormPatentRequestInfo" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID"
```

通用对象层次：

```json
{
  "CaseHandId": "<CaseHandId>",
  "FormCode": 120101,
  "DivisionalCase": {
    "CaseHandDivisionalCaseId": null,
    "OriginalApplicantNo": null,
    "OriginalApplicantDate": null,
    "DivisionalApplicantNo": null
  },
  "RequestInfo": {
    "CaseHandRequestId": null,
    "IsApplySameDay": false,
    "IsPublicAdvance": false,
    "IsExhibition": false,
    "IsPublished": false,
    "IsPublicForCommonProfit": false,
    "IsDisclosure": false,
    "IsGiveUpOn51Section": false,
    "IsRequestDelayReview1YearForUtility": false
  },
  "SpecificationInfo": {
    "AbstractDrawNumber": "<指定摘要附图的图号>"
  }
}
```

上面是字段层次示意，**不是可以无条件提交的默认值**。实际保存时应保留接口返回的 ID 和页面字段，只把操作者明确选择的声明写成 `true`。实用新型页面已经确认：`SpecificationInfo.AbstractDrawNumber` 必填且必须以数字开头；发明请求书应按其自己的页面校验填写，不能把实用新型字段机械复制过去。

下面命令中的 `$REQUEST_BODY`、`$CORRECTION_BODY`、`$OPINION_BODY`、`$SUBMIT_BODY` 都是**由操作者按上文结构构造的完整 JSON 字符串**，不是接口返回值。构造时先按对应章节读取现有数据，保留服务器返回的 ID，再修改需要变更的字段。

```bash
# 新增请求书
curl -sS -k -X POST "$API/CaseInfo/InsertFromPatentRequestInfo" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  -H 'Content-Type: application/json' \
  -d "$REQUEST_BODY"

# 已有请求书时改用：POST /CaseInfo/UpdateFormPatentRequestInfo
# 注意：$REQUEST_BODY 必须是当前页面填写后的完整 JSON，保留接口返回的 ID
```

### 上传申请原文：五书 + 原始混合文件

当提出申请页面显示"说明书、说明书摘要、权利要求书与附图"这张申请原文卡片时，正确结果不是四行，而是**五个拆分表单加一行原始混合文件**。该路线也适用于页面明确使用同一张卡片的其他流程。

先从官方表单列表读取该卡片的实际 `InstructionsFormCode`；当前常见卡片的代码可能显示为 `000000`，但命令行应以接口返回值为准。

**第一步：直传原始混合文件**

```bash
MIX_FILE='/填写本机原始混合文件路径'

MIX_UPLOAD_JSON=$(curl -sS -k -X POST \
  "$API/NoPermissionRequired/FileStorageUploadFile?1=1" \
  -H "Authorization: $TOKEN" \
  -H "Origin: $ORIGIN" \
  -H "Referer: $ORIGIN/login.html" \
  -H 'Language: zh-CN' \
  -F "file=@$MIX_FILE")

MIX_FILE_NO=$(python3 -c 'import json,sys; print(json.load(sys.stdin)["Data"]["FileNo"])' <<<"$MIX_UPLOAD_JSON")
test -n "$MIX_FILE_NO" || { echo '原始文件没有取得 FileNo'; exit 1; }
```

**第二步：按当前卡片解析五书**

```bash
MIX_PARSE_JSON=$(curl -sS -k -X POST \
  "$API/CaseInfo/UploadExistFileFormInstructionsAndImage" \
  -H "Authorization: $TOKEN" \
  -H "Origin: $ORIGIN" \
  -H "Referer: $ORIGIN/login.html" \
  -H 'Language: zh-CN' \
  -H 'Content-Type: application/json' \
  -d "{\"FileNo\":\"$MIX_FILE_NO\",\"CaseHandId\":\"$CASE_HAND_ID\"}")

python3 - "$MIX_PARSE_JSON" <<'PY'
import json, sys
data = json.loads(sys.argv[1]).get('Data') or {}
items = data.get('FileList') or []
names = {item.get('FormName') or item.get('FileName') for item in items}
required = {'权利要求书', '说明书', '说明书附图', '说明书摘要', '摘要附图'}
missing = sorted(required - {name for name in names if name})
if missing:
    raise SystemExit('解析结果缺少：' + '、'.join(missing) + '；停止保存')
print('五书解析通过：' + '、'.join(sorted(required)))
PY
```

只要五项不齐，就停止；不能自行把四项改名凑成五项，也不能继续调用保存接口。

**第三步：原样保存解析结果和原始文件**

`Data.FileList` 必须原样回传，`MixFile` 使用第一步返回的文件编号，内部键名是小写 `fileNo`、`fileName`。

```bash
MODIFY_BODY=$(python3 - "$MIX_PARSE_JSON" "$CASE_HAND_ID" "$MIX_FILE_NO" "$MIX_FILE" <<'PY'
import json, os, sys
parsed = json.loads(sys.argv[1])
data = parsed.get('Data') or {}
payload = {
    'CaseHandId': sys.argv[2],
    'IsUseXmlHand': True,
    'FileList': data.get('FileList') or [],
    'MixFile': {'fileNo': sys.argv[3], 'fileName': os.path.basename(sys.argv[4])},
}
print(json.dumps(payload, ensure_ascii=False))
PY
)

curl -sS -k -X POST "$API/CaseInfo/ModifyFormInstructionsAndImage" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  -H 'Content-Type: application/json' \
  -d "$MODIFY_BODY"
```

**不要改走旧的 `UploadHandMixFileWo` / `SaveHandCutMixFileWo`**，也不要用通用 `InsertFormFile` 拼装这张卡片。

**第四步：保存卡片设置并生成五书 XML**

```bash
curl -sS -k --get "$API/CaseInfo/GetFormInstructionsAndImage" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID" \
  --data-urlencode 'formCode=<InstructionsFormCode>'
```

若没有 `CaseHandFormInstructionsAndImageSettingId`，调用 `InsertFormInstructionsAndImageSetting`；已有 ID 则调用 `UpdateFormInstructionsAndImageSetting`。请求体：

```json
{
  "CaseHandFormInstructionsAndImageSettingId": "<已有设置 ID；新增时省略或为空>",
  "CaseHandId": "<CaseHandId>",
  "IsUseXmlFormatHand": true,
  "CaseName": "<页面当前案件名称>",
  "HasConfirmCaseNameIsNotSame": false
}
```

```bash
# 按页面是否显示“五书转 XML”执行
curl -sS -k --get "$API/CaseInfo/FiveFormsGetPackInfo" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID"

# 仅在页面要求生成或重新生成五书 XML 时调用
curl -sS -k --get "$API/CaseInfo/FiveFormsStartPack" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID" \
  --data-urlencode 'isForce=false'
```
