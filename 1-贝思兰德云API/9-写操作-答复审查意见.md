## 3.6 答复审查意见路线：100012

### 选择意见陈述书并取得通知书字段

```bash
curl -sS -k --get "$API/CaseInfo/IsHasCaseHandForm" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID" \
  --data-urlencode 'formCode=100012'

# 返回 false 时：
curl -sS -k --get "$API/CaseInfo/AddCaseHandForm" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  --data-urlencode "caseHandId=$CASE_HAND_ID" \
  --data-urlencode 'formCode=100012'
```

当前截图所示的"针对国家知识产权局于……发出的……陈述意见"对应 `OpinionStatementType=1`。通知书字段映射为：

```text
PostDate    → OpinionStatement.NoticeDate
NoticeName  → OpinionStatement.NoticeName
FaWenXLH    → OpinionStatement.NoticeNo
```

若页面选择的是补充陈述意见、药品专利期限补偿或其他单选项，字段会切换到对应的 `NoticeDate1/2/3`、`NoticeName1`、`NoticeNo1/2/3`；**不能把所有通知书字段同时填入**。

### 上传 Word 并保存完整表单

```bash
OPINION_FILE='/填写本机答复 Word 文件路径'

OPINION_UPLOAD_JSON=$(curl -sS -k -X POST \
  "$API/NoPermissionRequired/FileStorageUploadFile?1=1" \
  -H "Authorization: $TOKEN" \
  -H "Origin: $ORIGIN" \
  -H "Referer: $ORIGIN/login.html" \
  -H 'Language: zh-CN' \
  -F "file=@$OPINION_FILE")

OPINION_FILE_NO=$(python3 -c 'import json,sys; print(json.load(sys.stdin)["Data"]["FileNo"])' <<<"$OPINION_UPLOAD_JSON")
```

上传只完成文件存储，随后**必须**保存 `100012` 的完整对象。Word 上传对应 `OpinionStatementContentType=0`：

```json
{
  "CaseHandId": "<CaseHandId>",
  "FormCode": 100012,
  "File": {
    "FileNo": "<OPINION_FILE_NO>",
    "FileName": "<本机文件名>"
  },
  "OpinionStatement": {
    "OpinionStatementType": 1,
    "NoticeDate": "<PostDate>",
    "NoticeName": "<NoticeName>",
    "NoticeNo": "<FaWenXLH>",
    "OpinionStatementContentType": 0,
    "IsUseOtherProveFileHand": false,
    "HasAddExperimentData": false
  }
}
```

```bash
curl -sS -k -X POST "$API/CaseInfo/InsertFormOpinionStatement" \
  -H "Authorization: $TOKEN" -H 'Language: zh-CN' \
  -H 'Content-Type: application/json' \
  -d "$OPINION_BODY"

# 已有记录时改用：POST /CaseInfo/UpdateFormOpinionStatement
```

如果页面选择"填写文本"，则不是上传 Word，需按页面填写 `OpinionStatementText`；本节只描述"上传文件（word）"分支。
