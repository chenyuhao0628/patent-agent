## 附录 A 归档：当前账号无权限的接口

以下接口调用会返回 HTTP 200 但 `IsSuccess=false`、`Message="无访问权限"`。**不要反复重试**；要用先开通权限。

| 接口 | 用途 |
| --- | --- |
| `/AnnuaFeeMonitoring/GetAnnuaFeeMonitorings` | 年费明细列表 |
| `/AnnuaFeeMonitoring/GetAnnuaFeeMonitoringCount` | 年费明细计数 |
| `/AnnuaFeeMonitoring/GetAnnuaFeeMonitoringAbnormalFeeCaseList` | 年费异常案件清单 |
| `/AnnuaFeeMonitoring/GetAnnualFeeExceptionLogList` | 年费异常日志 |
| `/AnnuaFeeMonitoring/GetAnnualFeeBatchs` | 年费批次 |
| `/CaseInfo/GetNoticeList` | 全局官文列表 |
| `/CaseInfo/GetNoticeListOfDownloadFailCount` | 官文下载失败计数 |

**替代做法**：

- 年费：用 2.9 的汇总接口获取待缴件数与金额；需要定位具体案件时，先开通年费明细权限。
- 官文：通知书下载走 2.7 的「按流程取文件」路线，逐案号处理。
- **更彻底的办法**：年费金额与答复期限可以直接从 CPC 客户端取，不受贝思兰德权限限制，见 [CPC 分册 9-期限查询与通知书下载.md](../3-CPC电子申请客户端/9-期限查询与通知书下载.md)。

### A.1 权限是按模块开通的

实测 55 个代表接口，权限分布如下（判定依据：`Message` 为「无访问权限」= 无权限；为「系统错误」= 有权限只是缺参数）：

| 模块 | 权限 |
| --- | --- |
| 专利案件事务 | ✅ 基本全开 |
| 诉讼 / 无效 / 著作权 / 集成电路 / 商标 | 部分查询 ✅，费率与年费 ❌ |
| 客户档案 | 部分 ✅，业务员相关 ❌ |
| 委托 / 合同 | ❌ 全关 |
| 财务 | 绝大多数 ❌ |
| 年费监控明细 | ❌ |
| 规则引擎 `PatentRule` / `PatentNoticeRule` | ❌ |
| 报表 `Report` | ❌ |
| **批量递交 `CaseHandBatchSend`** | ❌ 大部分（菜单：批量处理管理-批量递交） |

**要用这些模块，先在贝思兰德后台开通权限**；接口本身是通的，属于授权问题。

**怎么知道该开通哪个菜单**：无权限响应的 `Ext.ActionInfo.ActionInfoList[].FullName` 就是完整菜单路径，例如：

```json
"Ext": {"ActionInfo": {"ActionInfoList": [{
  "FullName": "批量处理管理 - 批量递交 - 批量递交(batchdeliver) - 批量递交-打包状态获取"
}]}}
```

拿这个路径直接找贝思兰德开通即可，不用猜。

完整探测结果见 `reports/22-贝思兰德未明确事项与权限图谱-2026-09-11.md`。

**范围说明**：本分册只覆盖**专利案件主线**。无效（`Pi*`）、商标（`Tm*`）业务线不涉及；诉讼、著作权、集成电路、财务、合同、委托等模块暂未纳入，需要时参考 `reports/24-贝思兰德研究结项与范围清单-2026-09-11.md`。

## 附录 B 归档：无数据的接口与字段

以下接口与字段**权限正常**（`IsSuccess=true`），返回为空是系统中确实没有对应数据。**调用方式不需要改**，数据补齐后即可直接使用。

### B.1 接口级

| 接口 | 当前返回 | 说明 |
| --- | --- | --- |
| `/CaseInfo/GetCaseFeeList` | 空列表 | 案件无费用记录 |
| `/CaseInfo/GetCaseFeeListSummary` | `{ServiceFeeNotIncludeOfficialFee:[],OfficialFee:[],AmountStat:null}` | 同上 |
| `/CaseInfo/GetCaseFeeThirdPartFeeList` | 空列表 | 同上 |
| `/ExpressBill/GetExpressBillList` | `[]` | 无快递单 |
| `/CaseFile/GetCaseFileDownloadRecord` | `[]` | 该文件无下载记录 |
| `/WebSiteMessage/IsOpenWebSiteMessage` | `false` | 站内消息功能未启用（配置层面） |
| `/WebSiteMessage/GetWebSiteMessageCount` | `0` | 同上 |
| `/WebSiteMessage/GetWebSiteMessageList` | `[]` | 同上 |

### B.2 字段级

以下字段在列表行与流程明细中都存在，但**当前无值**。取值前应先判空，不要直接参与计算：

| 字段 | 说明 |
| --- | --- |
| `CaseProcExaminer` / `CaseProcExaminerTelephone` / `CaseProcExaminerDept` | 流程未录入审查员信息 |
| `CaseProcOfficeFeeTotal` / `CaseProcServiceFeeTotal` / `CaseProcOfficeAndServiceFeeTotal` | 案件未录入费用 |
| `CaseOfficaleFeeTotalAmount` / `CaseServiceFeeTotalAmount` / `CaseTotalCost` | 同上（案件级费用字段） |
| `CaseProcRemainingDays` / `CaseProcOverdueDays` | 系统未计算，**按 2.4 自行计算** |
| `CaseProcLegalDate` | **有值但不准**：没有工作日顺延，实测比官方期限早 2～20 天，见 4 分册 2.5.1 |
| `CaseProcCustomDate` | 有值，比 `CaseProcLegalDate` 早约 30 天，**不是官方期限** |
| `CaseProcClientDate` | 客户期限，**实测全空** |
| `CaseProcClientDateOverDays` / `CaseProcClientDraftDateOverDays` | 未计算 |
| `CaseProcNumberResponses` | 未录入 |
| `ProcProcessingDays` | 字段存在但恒为 `0`，不要用于判断 |
| `CurrentFlowStayHours` | 列表字段为空；**改用 2.5 的 `GetProcFlowRecord.StayHours`** |

> **两类归档的处理方式不同**：附录 A 是**权限缺失**（需开通权限）；本附录是**数据缺失**（接口正常，无需改动调用方式）。

## 附录 D 辅助接口索引

```text
POST /Auth/GetToken                          换取 Token
GET  /Auth/GetLoginInfo?checkVersion=false&isLogin=true   身份校验

GET  /CaseInfo/GetCaseProcFileList           流程文件列表
GET  /CaseInfo/GetCaseHandFileList           递交实例文件列表
GET  /CaseInfo/GetCaseHandProcRelateNoticeFileList  递交实例通知书文件（需事先校验格式）
GET  /CaseInfo/FiveFormsGetPackInfo          五书打包状态
GET  /CaseInfo/FiveFormsStartPack            开始五书打包
GET  /CaseInfo/FiveFormsResetPack            重置五书打包
GET  /NoPermissionRequired/FileStorageGetFile   文件下载
POST /NoPermissionRequired/FileStorageUploadFile?1=1   文件上传
GET  /NoPermissionRequired/GetFileUrl        取文件 URL
GET  /NoPermissionRequired/AutoAdjustWordImageInfo   图片自动调优

POST /CaseInfo/SubmitHandFlow                内部流程提交（会改变状态，见 10 分册）
GET  /CaseInfo/GetOfficialFormList           官方表单列表
GET  /CaseInfo/IsHasCaseHandForm             表单是否已选中
GET  /CaseInfo/AddCaseHandForm               选中表单
```

### D.1 文件上传的认证方式

上传接口的 Token 走 **query 参数**，不是请求头：

```text
POST /NoPermissionRequired/FileStorageUploadFile?1=1&Authorization=<token>
Content-Type: multipart/form-data
字段名自定，文件二进制直接上传
```

请求头里的 `Authorization` 会被该接口忽略。
