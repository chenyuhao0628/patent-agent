# 贝思兰德云 API 分册

> 总目录：[接入文档](../README.md)
> 根地址：`https://cloudapi02.baselandtec.com/v1`
> 站点：`https://cqgd.baselandtec.com`
>
> **范围**：本分册只覆盖**专利案件主线**。无效（`Pi*`）、商标（`Tm*`）业务线**不涉及**；
> 诉讼、著作权、集成电路、财务、合同、委托等模块暂未纳入。
> 完整范围清单见 `reports/24-贝思兰德研究结项与范围清单-2026-09-11.md`。

这是三册中**最常用的一册**，覆盖案件查询与业务操作。内容按功能拆成 15 个文件（另有归档 1 篇与[附录](./附录/README.md)一组），**按需读一节即可**。

---

## 分册状态

> **与微信 Agent 的边界**：本册包含会改变贝思兰德状态的人工命令行操作。当前微信 Agent 只自动接入**只读查询**和**通知书下载**，不会依据本册自动执行表单保存、上传、流程转交或撤案。
>
> 本文档是通用操作说明，不绑定某个案号、专利名称或某一份本地文件。文中的 `<...>` 是运行时从接口返回或由操作者填写的变量，不能照抄成固定值。

## 推荐读法

```text
只查案件：1 → 2 →（需要时 3 / 4 / 5 / 6）
要增量同步：1 → 14
要查授权/获证：1 → 15
要操作案件：1 → 7 / 8 / 9 → 10
要做官方递交：1 → 11（贝思兰德服务端代发）或转 [CPC 分册](../3-CPC电子申请客户端/README.md)
遇到报错：1 的 1.3 节 → 13（写操作业务码）→ 99（权限/无数据）
要写报错文案：13 → 附录/业务码中文对照.md
```

只读查询可以随时执行。写操作会改变真实业务数据，执行前请读完整条路线，不要跳读。
