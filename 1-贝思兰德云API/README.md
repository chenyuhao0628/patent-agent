## 为什么放在 0001

这套文档记录的是**贝思兰德后端接口**本身（认证、只读查询、写操作、官方递交、业务码），
与 patent-agent 这个桌面应用的源码无关。放在产品仓库里只会产生第二份副本。

历史上这里是同一套 15 篇的副本，两边各自单独演进，出现过内容分叉：
`0001` 那份多了参数补全实测、多账号 Token 隔离、官文文件直链等内容，
本仓库这份则独有一段「跨机部署」说明。2026-09-23 已把本仓库的独有内容全部回流到 `0001`，
并把此处改为指针。
