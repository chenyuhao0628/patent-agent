# 专利工作台 · 桌面开发版 0.3.0

独立桌面应用，覆盖案件管理、答复、五阶段撰写、可选的个人独立审查和贝思兰德内部流转。使用本地文件和自有界面，通过结构化接口接入 OpenCode。

## 安装与更新

- macOS Apple Silicon：`release/PatentWorkbench-0.3.0-macOS-arm64.pkg`，约 173 MiB；也保留同版本 `.app`，约 441 MiB。
- Windows x64：`release/PatentWorkbench-0.3.0-Windows-x64-Setup.exe`，约 152 MiB。

安装器沿用固定应用标识，覆盖程序并保留用户数据。Mac 使用所选安装域的“Applications”目录；本机已安装到 `~/Applications/专利工作台.app`。Windows 使用 NSIS 安装器，保留安装路径与 AppData。旧便携版应退出后使用安装器，原便携 EXE 不属于安装器管理的文件。

账号、加密凭证和本机设置放在应用数据目录，原始申请库与工作目录独立选择。Mac 安装与重复覆盖已经实测；Windows 已交叉构建和检查安装器内容，尚未实机验收。当前包未做发行签名 / macOS 公证，也没有在线自动更新服务。版本与 SHA-256 以 `release/release-manifest.json` 为准。

## 版本规则

使用“主版本.功能版本.修复版本”：重大产品版本或不兼容变化增加第一位；新增功能增加第二位，并将第三位归零；兼容的小修复增加第三位。主版本增加时，后两位归零。仅更新文档不自动升级安装版本。

本次从 0.2.11 升到 **0.3.0**，原因是新增本机撰写参考材料管理；后续同系列小修复为 0.3.1，下一组新功能为 0.4.0。仍处于开发阶段，达到明确的正式交付标准后再发布 1.0.0；版本增加不代表未验收能力已完成。旧版编号保留为历史事实，不回改旧证据和安装清单。

## 撰写参考材料

1. 打开当前处于撰写阶段的案件，在“撰写 → 本案参考材料”点击“添加参考材料”。
2. 从本机多选技术交底、图纸或参考专利：支持 DOCX、DOC、PDF、TXT、Markdown、PNG、JPEG，每次 1–12 份，每份不超过 20MB。
3. 文件复制到本案的 `01_通知与材料/撰写参考/`，原件保留，同名文件分别保存。新添加文件自动勾选，可以取消不需要的材料；退出或离开页面后再进入，需要重新选择本次材料；只有本次勾选内容进入撰写任务的冻结副本。
4. “打开查看”使用本机默认应用打开本案副本；“移出列表”只取消手动参考材料的列表关联，保留磁盘副本和历史任务输入，不影响其他案件。同步通知和原始申请不能在此移除。
5. 添加成功表示文件已保存，不表示解析成功。点击生成后，在本阶段任务／工具记录查看读取结果与失败原因；旧 DOC、扫描文件等仍受转换器和模型能力约束。没有文件时可以直接输入文字构思。

任务运行、阶段不可编辑或案件同步过程中不允许改动参考材料；取消系统选文件对话框不会添加材料。文件导入是本机复制，不会向贝思兰德上传。开始模型任务后，所选内容按当前模型配置供 AI 读取。

## 对话与队列

- 答复／补正共用“本案对话”，正式办理步骤在同页打开，旧答复链接继续可用。
- 误建空的附加讨论可删除；已有内容可归档和恢复。主讨论、独立复核和关联任务受到保护。
- 审查默认展示待审稿件；审查记录按实际执行次数计算。内部流转按当前可办理的贝思兰德流程显示，不依赖旧的本地定稿字段。

## 案件与办理

- 每案只有一个当前办理，按真实流程节点显示。官方回执进入“等待官方处理结果”，不等于案件结案；等待官方使用独立侧栏。
- 案件库支持公司名称、点击表头排序、拖动列宽、专利类型和办理业务组合筛选、批量归档。申请、审查意见和补正分色显示；勾选框与筛选字号已统一。
- 提出申请使用内部期限。其他业务使用可信官方期限优先、贝思兰德计算期限兜底，显示来源；当前未接入 CPC。
- “其他”是未归入申请 / 答复 / 补正等主要业务的分类，不代表结案。只在读取到明确 `IsFinishCase=true` 后本地归档，不向贝思兰德写入结案操作。
- 同步范围是当前账号本人负责的案件，启动、登录、目录配置后检查，运行期间每五分钟补查。原始库只读，匹配结果复制到独立案件目录。
- 工作目录迁移先预览、复制和校验，再切换目录。原始申请库不迁移，旧工作目录保留。

## Agent、审查与提交

模型设置按“供应商 → 该供应商的模型”组织，支持自定义 URL、Key、协议、上下文、最大输出、思考等级及获取上游模型。OpenCode Go / DeepSeek V4.1 / Responses 已真实调用，按会话携带所需请求头。

答复保持材料确认、意见分析和策略讨论、用户选定策略、起草 / 修订、独立复核与定稿。撰写使用内置 draft 标准技能逐阶段确认；个人审查使用独立上下文与准确稿件版本。侧栏“审查”默认汇总所有审查记录，案件内同步展示，另有待审稿入口；审查可选，提交后记录保留。

“提交”是案件独立功能页，位于贝思兰德流程之后。自动准备材料勾选和表单，由用户核对后保存、回读并转交下一内部办理人。本地原件、完整稿件和历史均保留，不把内部转交当作官方递交。本轮未执行真实上传、删除递交项、保存表单或转交。

Word 使用已核定的桌面申请模板，以及秋泽案准确答复模板 `一种汽车内饰用皮革裁切装置_第一次审查意见答复.docx`。模板、标准 draft / review 技能随应用提供；完整附图、复杂公式和真实专利内容质量仍需单独核验。

## 对比文件、扩展与 Word 定稿

- 通知由贝思兰德同步，不再单独开发批量通知导入。同步后识别当前通知的公开专利编号，通过智慧芽下载 PDF 到本案当前轮次；已下载材料复用，失败显示原因，可在材料页重试或补充公开号。纯扫描页、缺少完整公开号或非专利文献需人工核对，不能假称全部识别完成。
- 设置 → 文档工具 → 智慧芽对比文件支持保存 Key / Client ID:Client Secret、导入本机旧专利应用的钥匙串配置及测试。仅向智慧芽发送公开号；凭证按当前账号加密保存，不依赖旧仓库运行。Windows 可在设置中填入凭证。
- 设置 → 技能与 MCP 可导入含 SKILL.md 的文件夹（正文、文本参考和脚本）、直接编写技能、粘贴 mcpServers / OpenCode mcp JSON、启停、编辑、删除和测试连接。远程支持 URL / headers，本地支持 command / args / env；OAuth 交互登录和技能二进制资产导入尚未接入。启用扩展进入下一次真实 Agent 任务；本地 MCP 需开启任意命令。
- 本地 MCP 的默认 HOME 在 tools/mcp/home，npm 缓存在 tools/mcp/npm-cache；显式环境变量可以覆盖。MCP 按自身工具能力访问文件或网络，不是案件沙箱。Header / env 凭证加密保存，编辑时用占位符保留原值，不显示秘密。扩展是本机配置，不随案件云目录迁移。
- 起草 / 修订要求输出本次修改部分的**完整正文**，界面可核对权利要求书、说明书和摘要；无修改时明确保存空范围。修改正文产生新版本并使旧复核失效。旧版本缺少完整正文时，先补齐并重新复核，不能从修改建议推测全文。
- 定稿按提供的 DOCX 母版填充，生成意见陈述书、各修改部分、修改依据、内部复核说明，正式目录不再新建 TXT / Markdown 替代品。原始文件、完整稿和历史版本保留。提交页自动带入采用稿的修改部分并预选清单，由用户核对后执行保存 / 转交。
- 补正内容由 Agent 准备，界面只填写 **文件名称、具体位置、补正前、补正后** 四项，可增加多条。其他表单信息由程序从贝思兰德读取并保留，既有 ID 不丢失；本地定稿保存补正字段记录，提交时写入 100006 补正表，不生成或上传补正说明 Word。字段编辑同样产生新版本并使旧复核失效。答复 / 补正只要求本次勾选修改部分成功解析，提出申请仍要求完整五书。
- 自动填充现已验证文字正文、中文字体、分节页眉页脚及跨页排版。附图、复杂公式仍使用经核对的现成 Word 文件，不能用文字占位当作完整图形导出；真实案件内容质量及远端提交需单独验收。

## 工具权限与体积

设置 → 文档工具提供联网检索、软件下载、任意命令与软件安装、预设转换组件自动安装四个选项。新增下载与命令默认关闭；设置本机共用，运行中需先停止任务再修改。

- 开启任意命令后，Agent 可执行 shell / PowerShell、调用已有 WPS / Word / 系统工具、安装任意轻量库或其他软件。没有 Office 白名单。命令以本机当前用户权限运行，可访问其他文件和联网，默认目录不是沙箱；命令联网不受独立检索 / 下载开关限制。
- `discover_tools` 返回实际检测到的工具及默认位置；WPS 安装检测不代表已验证该版本的自动转换接口。先探测再调用，不猜测其命令行参数。
- `prepare_material` 仅复制本次选定材料；Agent 用 `execute_command` 另存转换 / OCR 结果，再用 `read_work_file` 阅读或视觉核对。来源材料 ID、实际读取摘要和命令记录保留。应用不主动向命令环境传递凭证或整个案件库，但开放任意命令不是操作系统隔离。
- `download_file` 支持任意公开软件 URL，下载到集中目录；逐跳检查地址，限制 2 GiB，支持预期 SHA-256 校验，不自动运行。没有预期摘要时仅报告实际摘要，不冒称可信验证。命令可用包管理器自行下载与安装。
- `web_search` / `web_fetch` 通过 Exa 查询公开网页，保留来源；不携带账号凭证，不把外部资料作为操作指令。
- Mac 原有系统 `textutil` 可读普通旧 DOC，无需下载。LibreOffice 固定版本安装仍是可选快捷方式；完整引擎不放进主包。扫描 PDF 已提供页图和模型视觉。

工具根目录是 Mac `~/Library/Application Support/专利工作台/tools/` 或 Windows `%APPDATA%\专利工作台\tools\`。`downloads` 保存下载文件和来源记录；`custom` 默认保存自装工具、Python 虚拟环境、npm 依赖和缓存，应用覆盖更新时保留。本次命令 HOME / 临时文件和材料副本留在各任务自己的 `command-work`，不进入共享原始库。Agent 若指定系统安装位置，则由相应安装器管理。

命令、退出码、限长输出保存在各本机任务的 `tool-audit/*.json`，界面保留调用记录。停止会终止所管理的命令进程；已经独立启动的 GUI 应用或系统服务不保证随任务关闭。主程序仍只捆绑 OpenCode 和文档阅读组件，不要求安装旧项目源码。
