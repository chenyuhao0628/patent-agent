# 专利工作台 0.20.1

独立 macOS / Windows 桌面应用，覆盖案件管理、答复与补正、五阶段撰写、可选独立审查和贝思兰德内部流转。应用管理业务与文件，模型通过随包 OpenCode 接入，无须旧项目源码。

## 当前状态

- 当前源码为 **0.20.1 候选测试版**：答复 / 补正支持权利要求书、说明书等多个独立修改文件；补充两来源同字节对照、分阶段失败提示及保存中断后的精确回读。保留此前案件、答复、撰写、独立审查与公式处理能力。
- 上传相关源码全量测试 787/787、类型检查与生产构建通过；真实组件合成验证覆盖多文件与保存交互。**用户报告的工作台稿件真实提交失败根因尚未证实**，合成通过不等于真实贝思兰德验收。安装后由用户实机核对。
- 本轮源码未提交或推送，安装包不对外发布。0.19.1 的既有原生验证见 [真实验收记录](evidence/native-acceptance-20261001.md)，不能作为 0.20.1 的验收。当前进度和证据见 [实施计划](EXEC_PLAN.md)。

## 安装

本轮 **0.20.1 候选测试版**已构建并核验，见 [当前安装清单](release/release-manifest.json) 与 [制品校验证据](evidence/release-0.20.1-20261009.json)。macOS Apple Silicon 使用 .app / .pkg，Windows x64 使用 NSIS .exe。打包前实际存在的 0.19.1 三项旧制品原地保留，前后摘要一致。实机测试步骤见 [0.20.1 测试说明](docs/TESTING-0.20.1.md)。

安装器使用固定应用标识并保留用户数据；Mac 安装至所选安装域的 Applications，Windows 保留安装路径和 AppData。账号、加密凭证和本机设置在应用数据目录；工作目录与原始申请库单独选择。当前包无发行签名、macOS 公证及在线自动更新。

## 开发

```sh
npm ci
npm test
npm run build
npm run desktop
npm run package:release
```

`npm test` 覆盖领域、主进程和打包脚本；构建包含类型检查；打包前在 `.lab/agent-runtime` 准备固定版本的 OpenCode，打包失败保留上一版安装包。按本次授权执行提交、打包、推送和发布；文档整理不升版本、不重跑无关业务验证。

本版继续保留中断续办与任务产物进度：撰写和独立审查可以继续当前未完成任务；按正文、修改依据及申请文件部分显示已保存与待补齐内容。恢复先核对范围和摘要，结果不明的操作不自动重放；提示不增加定稿或内部转交门槛。
