# 专利工作台 0.20.1

独立 macOS / Windows 桌面应用，覆盖案件管理、答复与补正、五阶段撰写、可选独立审查和贝思兰德内部流转。应用管理业务与文件，模型通过随包 OpenCode 接入，无须旧项目源码。

## 当前状态

- 当前安装版本为 **0.20.1 候选测试版**；本分支正在完成 0.21.0 功能版交付，旧包不会因源码更新自动变化。
- OpenCode 已迁移 v2；当前打包源 2.0.27。按账号、案件、阶段与分支保存会话，完成会话可重开接续；设置显示缓存统计与后台自动更新。更新不锁死补丁版本，先验证、空闲切换并保留回退。
- 已按阶段本地提交，未推送或发布。v2 阶段全量 827/827、构建及真实二进制的四协议合成检查通过；完整证据与最终制品状态见 [实施计划](EXEC_PLAN.md)。
- 用户此前报告的工作台稿件真实保存失败根因尚未证实；合成通过不等于真实贝思兰德验收。历史原生、真实模型与 Word 结果见 [真实验收记录](evidence/native-acceptance-20261001.md)，不能替代本轮验收。

## 安装

当前已存在的 **0.20.1** 三项制品见 [安装清单](release/release-manifest.json)，2026-10-12 重核结果见 [制品审计](evidence/audit-20261012/release-probe.json)。macOS Apple Silicon 使用 .app / .pkg，Windows x64 使用 NSIS .exe。安装步骤见 [0.20.1 测试说明](docs/TESTING-0.20.1.md)；最终 0.21.0 制品将在全部检查完成后生成。

安装器保留应用数据；账号、凭证和本机设置在应用数据目录，工作目录与原始申请库另行管理。当前包无发行签名和 macOS 公证，整体应用通过安装包更新。新源码中的 OpenCode 后台可自动验证并更新，和应用安装包更新分开。

## 开发

```sh
npm ci
npm test
npm run build
npm run desktop
npm run package:release
```

`npm test` 覆盖领域、主进程和打包脚本；构建包含类型检查；打包前在 `.lab/agent-runtime` 准备通过兼容检查的官方 OpenCode，清单记录实际版本与摘要。保留旧制品时使用 `--preserve-old`；打包失败保留上一版。本轮仅本地提交与构建，不推送或发布。

本版继续保留中断续办与任务产物进度：撰写和独立审查可以继续当前未完成任务；按正文、修改依据及申请文件部分显示已保存与待补齐内容。恢复先核对范围和摘要，结果不明的操作不自动重放；提示不增加定稿或内部转交门槛。
