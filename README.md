# 专利工作台 0.18.0

独立 macOS / Windows 桌面应用，覆盖案件管理、答复与补正、五阶段撰写、可选独立审查和贝思兰德内部流转。应用管理业务与文件，模型通过随包 OpenCode 接入，无须旧项目源码。

## 当前状态

- 当前源码为功能版 **0.18.0**。保留现有架构，案件仅显示当前撰写 / 答复 / 补正业务入口，历史集中查看；撰写支持按材料选择起点、明确采用较早完成稿，修复返回步骤后旧上下文结果被误用的问题。任务卡片、依据和操作区统一视觉，完成稿的任务记录默认折叠，正文更早进入阅读区域。
- 全量测试 **768/768**、类型 / 生产构建及三项本地制品校验通过。以真实案件组件和合成 API 验证 1440×900、1920×1080、1280×800；额外检查扣除窗口边框后的高度与 820px 窄窗口。旧版九项制品保留，源码尚未提交或推送。统一面板注册仅完成可行性评估，尚未实施。
- 源码、自动化、真实服务、桌面 GUI 和安装验收分别记录；完整交付验收仍未完成。当前缺口见 [实施计划](EXEC_PLAN.md)，已完成记录见 [模块归档](docs/archive/README.md)。

## 安装

以 [当前安装清单](release/release-manifest.json) 所列的 **0.18.0** 为准：macOS Apple Silicon 使用 .app / .pkg，Windows x64 使用 NSIS .exe。本轮保留 0.15.3 / 0.16.0 / 0.17.0 共九项旧制品，摘要核对未变。验证路径和验收边界见 [实施计划](EXEC_PLAN.md)。安装制品仅保存在本机；此次没有提交、推送、发布或覆盖安装。

安装器使用固定应用标识并保留用户数据；Mac 安装至所选安装域的 Applications，Windows 保留安装路径和 AppData。账号、加密凭证和本机设置在应用数据目录；工作目录与原始申请库单独选择。当前包无发行签名、macOS 公证及在线自动更新。

## 开发

```sh
npm ci
npm test
npm run build
npm run desktop
npm run package:release
```

`npm test` 覆盖领域、主进程和打包脚本；构建包含类型检查；打包前在 `.lab/agent-runtime` 准备固定版本的 OpenCode，打包失败保留上一版安装包。按本次授权执行提交、打包、推送和发布；文档整理不升版本、不重跑无关业务验证。

本版继续保留中断续办与任务产物进度：撰写和独立审查可以继续当前未完成任务；按正文、修改依据及申请文件部分显示已保存与待补齐内容。恢复先核对范围和摘要，结果不明的操作不自动重放；提示不增加定稿或内部转交门槛。
