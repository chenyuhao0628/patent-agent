## 原因与范围

0.22.0 的这两个页面依赖 `agent-workbench.css`，该文件只由单案 AgentWorkbench 引入。隔离 `.app` 复现得到：冷开时任务行是普通 block，流转节点是默认编号列表；进入案件后分别恢复 flex / grid；硬刷新后再度丢失样式。两条任务与两个案件的身份和数量保持，未请求真实服务。

本版另制定 [UI 规范](design/ui-standards.md) 与 [完整统一方案](design/ui-unification-plan.md)。它们是后续页面对齐和迁移的基准，不表示所有旧界面已在 0.22.1 统一。

## 安装与现场检查

使用 [当前安装清单](../release/release-manifest.json) 中对应平台的 0.22.1 `.app` / `.pkg` / `.exe`。先保存并退出现有程序，再按原位置安装并核对版本；此次开发未覆盖用户安装。

1. 重新启动，直接点内部流转，已有案件的身份、状态、节点与进入按钮应完整布局；搜索 / 清空后数量正确。
2. 直接点工作任务，已有任务行、时间、状态和两项导航动作对齐；打开任务后应回到该案件的确切记录。
3. 进入案件再返回两个全局页面，样式与首次打开一致；重新启动或刷新不恢复为普通编号列表。
4. 核对原有案件、稿件、任务记录和工作目录仍可读取。界面修复不代表历史同步差距、真实贝思兰德保存故障已经解决。

Windows 实机、macOS pkg 覆盖安装、发行签名 / 公证、真实模型与生产业务写入仍分别验收；包内核对不替代这些证据。
