# 使用说明

对应应用 **0.22.1**，2026-10-12 按当前界面与代码核对。0.22.1 修复内部流转 / 工作任务独立首开时缺样式，操作与业务流程沿用 0.22.0。安装文件和平台验收见 [交付索引](releases/README.md)，实现差距及未验收项见 [当前计划](../EXEC_PLAN.md)。本页说明使用方式，不将功能入口或合成检查等同真实业务验收。

## 首次设置

1. 从当前安装包启动桌面应用。需要同步个人案件时，在「设置 → 贝思兰德账号」登录；本地案件可以先在本机办理，之后显式关联已同步案件。
2. 在「设置 → 文件与目录」选择总工作文件夹并保存。原始申请库单独选择，不能与工作文件夹相同或位于其中；原始库用于只读匹配，工作文件夹保存案件副本与成果。
3. 在「设置 → 模型服务」配置供应商地址、密钥、模型和实际支持的协议，保存并测试连接，选择默认模型 / 推理设置。导入旧 DSH 配置是可选入口，独立安装无需旧项目源码。
4. 检查「模板与规则」「文档工具」「技能与 MCP」中本次需要的能力。Word 模板随应用提供；不要用模板入口存在推断复杂版式已经验收。

| 设置分类 | 用途 |
| --- | --- |
| 贝思兰德账号 | 登录、退出及记住登录 |
| 文件与目录 | 原始申请库、工作目录、共享读取、迁移与目录整理 |
| 模型服务 | 供应商、模型、协议、密钥、推理设置与连接测试 |
| 模板与规则 | 已确认的内置模板与按业务类型组织的规则说明 |
| 文档工具 | 检索、下载、命令和转换权限，以及智慧芽凭证配置 |
| 技能与 MCP | 导入、编写、启停和测试本机扩展 |
| 诊断日志 | 导出运行元数据以协助排查 |
| 应用与更新 | 桌面行为、安装更新说明和 OpenCode 后台兼容更新 |

已有案件时通过「文件与目录」中的迁移功能变更工作位置。使用云盘时等同步完成，再由一台电脑编辑同一案件；本机对话、任务、后台会话和凭证不会随案件共享目录自动迁移。

## 全案与单案

侧栏的「案件库」「等待官方」「工作任务」「审查队列」「内部流转」「案件状态」查看当前账号的汇总。打开案件后，「概览」「材料」、当前业务、审查、历史、成果和流程等页签绑定本案；可见和可编辑入口随当前办理状态变化。

全局「审查队列」与本案「稿件审查」分别提供汇总和办理入口。切换全案或单案页面不会停止已经运行的后台任务；从所属案件或任务记录中明确停止。只读历史入口不会启动新的办理，失效的旧链接会显示不可用。

## 案件

每案只有一个当前办理。案件标题显示当前状态，业务导航只显示当前的「撰写」「答复」或「补正」；往期阶段和成果在「办理历史」查看，不作为同时办理的入口。案件库可搜索、筛选、排序、调整列宽、批量归档，并按当前状态查看。

同步范围是当前账号负责的案件。启动、登录和选定工作目录后会增量同步。案件库「刷新案件」重新扫描个人案件列表，用于发现新分配案件、归属变化和此前未知的个人流程。案件内「刷新本案」只更新当前案件的已知个人流程、附件清单、备注、流程明细和官方结论；以不可变 `FileNo` 识别远端材料，只下载新增或尚未就绪的文件，远端文件名变化只更新显示信息，不改动其他案件。没有固定周期的自动同步。

原始申请库只读。匹配结果复制到案件目录，原件保留。

期限显示来源。提出申请使用内部期限；其他业务优先使用官方期限，否则使用贝思兰德计算期限。

官方回执进入「等待官方」，不等于结案。授权或驳回出现后，案件离开该列表，状态显示结论本身。未见结果只表示官文清单里没有对应结论，不是未授权。

只在读到明确结案标记后做本地归档，不向贝思兰德写入结案。

工作目录迁移先预览、复制和校验，再切换。设置里可以整理当前账号的系统生成目录和成果文件名；未知目录、冲突、符号链接和用户文件不动。

## 答复与补正

答复和补正在当前案件的「答复」或「补正」入口办理，使用本案对话工作区。步骤是材料核对、策略讨论、起草修改、可选独立复核、用户定稿。默认办理当前步骤，也可以只讨论。

分析完成前不能选定策略，选定前不能起草。采用稿、修改正文或补正字段会形成新版本，并使旧复核失效。定稿前可以微调正文和补正条目。未保存的微调会阻止确认定稿。定稿可以撤销，已有正文、补正和定稿记录保留。

停止或退出后保留已输出内容。继续使用当前公开上下文，重试在新分支执行。切换分支不回滚案件文件。普通补充消息在任务运行中进入待发送队列；编辑历史消息重发或重新生成历史回复时先停止当前任务，旧任务的迟到输出不会并入新任务。

## 撰写与独立审查

撰写包含方向构思、技术方案与保护架构、说明书、权利要求书和申请文件整理五类步骤。尚未开始或新一轮尚无成果时，可按已有材料选择「撰写起点」；选择起点不会调用 AI，也不把未办理的前序步骤标为已确认。缺少内容可用「补充或修改前序步骤」返回补充。参考材料从本机复制到 `01_通知与材料/撰写参考/`，支持 DOCX、DOC、PDF、TXT、Markdown、PNG、JPEG，每次 1–12 份，每份不超过 20MB。只有本次勾选的材料进入任务；离开页面后再次进入须重新选择。移出列表不删除磁盘副本。

审查使用独立上下文和指定稿件版本，可选，不阻塞定稿和提交。

### 选择撰写成果版本

新修改任务停止或失败时，先显示该任务的状态和已保存产物，不自动采用旧完成稿。可在「选择本步骤成果版本」中明确选择较早完成稿；正文、本次任务产物和依据同时切换到该版本，再点击「确认采用此版本」。阅读完成稿时，「本次任务记录」默认折叠；展开可查看该版本的产物、依据与工具记录，待核对数量仍显示在标题。新任务记录独立保留；继续未完成任务会返回该任务的状态。返回前序补充后，旧成果仍可在阶段历史查看，但不会自动作为本轮确认结果。

## 任务依据与核对

任务记录中的「本次任务依据」默认折叠，可以展开查看本次返回的材料页码 / 行号、版本摘要、引用核对结果，以及用户原话和界面确认的来源。长输入在界面显示节选，完整原文保留在本机任务快照中，模型可分段读取。撰写进入下一阶段后，仍保留已确认阶段各轮用户输入；问题和假设不会自动标记为确认。

当前通知存在已知未读范围、引用材料或版本不符、逐字引文与原文不符时，Agent 在同一任务中收到具体补读或修正说明。普通参考文件只读了相关部分、扫描页没有文字层、缺少结构化引用等情况显示提示，不新增人工定稿或提交门槛。

「原文匹配」仅表示冻结版本、已返回范围和原文片段匹配，不表示论证、专利质量或 Word 版式已经验收。旧任务没有新证据字段时继续可查看，不追溯标记为已核验。

## 中断后继续与任务产物

- 撰写、独立审查停止或失败后，当前未完成任务可点击“继续未完成任务 / 继续未完成审查”。使用该任务原要求和原材料；要采用新输入或新版本，请重新生成。
- 进度卡片显示正文、修改依据、申请各部分等已保存与待补齐项目。展开续办资料可核对文件摘要和未确认操作；保存检查点不等于定稿或 Word 验收。
- 恢复不自动重复结果不明的命令、下载或安装。已核对的任务工作文件可复用，变化文件保留原位并提示，不覆盖用户文件。
- 普通待核对提示不妨碍原有办理操作，独立审查仍为可选步骤。

## 提交与内部转交

在当前可办理的贝思兰德案件中进入「提交」。程序准备材料和表单，用户核对后再保存、回读并转交下一内部办理人。本地案件须先显式关联远端案件及可办理流程。当前页签顺序与需求的差距见 [当前计划 D1](../EXEC_PLAN.md#实现差距)。

补正没有单独的说明 Word。逐条补正在「本次材料」填写，可先存为本机草稿；保存到贝思兰德时写入补正表。答复使用意见陈述书和本次修改部分。提出申请要求完整五书。

保存、内部转交和官方递交是三件不同的事。保存中断后刷新并按原办理节点、原接收人回读，不自动再次转交。清理远端草稿必须回读确认目标文件关联和补正条目确已清空；部分完成时保持锁定并继续核对。已转交的事项不能重复转交。

另一台已登录的电脑可以读到服务端已经保存的材料和表单。本机没有文件时，可以按不可变 `FileNo` 下载远端稿件查看；文件名仅作为展示标签，同名文件不用于猜测身份。

## 稿件与公式

界面用离线 KaTeX 显示公式。导出的申请文件和答复文件使用随应用提供的 Word 模板，公式写入 Word 可编辑公式。从 DOCX 读取时保留 OMML 公式、段落、表格、分节页眉和可支持图片；修订痕迹、旧公式域及其他不能无损解释的结构会明确报错，不以遗漏内容的纯文本替代。

附图和复杂公式使用已经核对的 Word 文件。文字或公式渲染不能代替图形验收。

对比文件来自通知中的公开号，经智慧芽下载到当前轮次。凭证按账号加密保存。扫描页、不完整公开号和非专利文献需要人工核对。

## 会话、上下文缓存与更新

任务记录可展开「会话与上下文缓存」，查看「已接续 / 新上下文」、会话 ID、运行时版本、缓存用量和自动压缩次数。同案的不同阶段、讨论、分支、稿件 / 材料版本或模型上下文可以使用不同会话；各案件之间隔离，不能把一个案件永久等同一个会话 ID。

公开对话和已保存成果在退出后保留。后台会话也保存在本机，范围一致的已完成会话可以续接；停止或失败后的隐藏执行不直接恢复，续办按当前公开记录及经核对的文件继续。保留会话、允许缓存、供应商实际报告缓存命中是不同状态；未报告命中时界面如实显示，不保证缓存永久有效或任务必然变快。

「设置 → 应用与更新 → OpenCode 后台」默认开启「自动检查并安装兼容更新」：启动及运行期间每 6 小时检查，候选通过兼容性验证且任务全部结束后切换；有上一可用版本时可以回退。额外计费的定时缓存预热保持关闭。

OpenCode 更新与应用安装包分开。应用整体仍通过新安装包更新，更新前保存并退出；按原安装位置更新后核对账号、设置和案件目录。平台实际安装验收状态见交付索引。

## 工具

设置 → 文档工具有四项：联网检索、软件下载、任意命令与软件安装、预设转换组件自动安装。下载和任意命令默认关闭。联网检索默认开启。修改这些设置前先停止正在运行的任务。

任意命令以本机当前用户权限执行，可以访问其他文件和网络。它不是沙箱，也不受检索、下载开关限制。应用不把凭证或整个案件库放进命令环境。

命令记录保存在对应任务的 `tool-audit`。停止任务会结束由该任务启动的命令；已经独立打开的图形程序不保证随任务关闭。

技能和 MCP 在设置中导入、编写、启停和测试。本地 MCP 需要先开启任意命令。扩展配置留在本机，不随案件目录迁移。

诊断日志可用「导出最近 10 分钟日志」保存到本机。日志不包含密钥、请求正文、案件正文和完整路径。
