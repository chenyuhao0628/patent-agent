# Agent、运行时与会话

核对基线：2026-10-12 / `027c9de` / 应用 0.22.0。本文描述项目实际实现，供应商协议能力以配置及验证结果为准；不把捆绑版本当作官方最新版本，也不从版本号推断速度或质量。

## 装配与执行

| 层 | 源码 | 职责 |
| --- | --- | --- |
| 业务任务 | `desktop/agent-host.ts`、`professional-host.ts` | 冻结案件 / 流程 / 版本、用户请求与材料，管理步骤、任务、回执和恢复 |
| 执行合同 | `desktop/agent-contract.ts`、`agent-integration.ts` | 将业务输入映射到 Runner，转发结构化事件，核验产物文件；独立复核不带主讨论 |
| 引擎装配 | `desktop/engine-adapters.ts`、`runtime-manager.ts` | 校验合同和能力，为任务取得运行时租约，任务结束后释放 |
| OpenCode | `desktop/agent-runner.ts`、`opencode-v2.ts` | 启动受控服务、使用公开 API 与结构化事件；不以终端自然语言猜状态 |
| 请求与工具 | `desktop/agent-proxy.ts`、`conversation-context.ts`、`agent-broker.ts` | 当前公开上下文、模型协议、白名单工具、受管读写、阅读证据与产物检查 |

源码配置支持 Responses、Chat Completions、Anthropic Messages、Gemini GenerateContent 四个协议值，定义于 `src/domain/models.ts`。这表示已有协议适配，不能推定任意供应商、任意模型或推理档位都已验收。模型、地址、密钥、协议、上下文 / 输出限制和思考设置由模型配置决定。

运行器默认任务时限为 3,600,000 毫秒，可由明确输入覆盖。产物修复连续两次没有有效进展时停止自动循环，任务保留检查点；失败、停止和未通过的产物不推进业务状态。业务完成依据受管产物与状态机，不是模型回复“完成”。

## 三种不同的保存

| 数据 | 管理位置与含义 |
| --- | --- |
| 案件文件 / 稿件 / 成果 | 受管工作目录和工作区记录；按身份、版本、摘要及作用域保存 |
| 公开对话 / 任务 / 恢复资料 | 本机业务 Host 与任务目录；退出和重开后用于展示、重新核对及明确续办 |
| 引擎会话 | `engine-sessions.ts` 的独立本机数据库与范围绑定；保留后台记录，不允许任意旧隐藏上下文跨任务重放 |

后台会话范围包含账号、案件、办理流程、讨论、分支、任务种类、有效上下文摘要以及模型运行上下文。同案可以有多个隔离会话，不能把“按案件隔离”写成“整个案件永远只有一个 session ID”。只有完成且范围相符的会话才可复用；停止或失败后的隐藏执行不直接恢复。引擎更新使用空闲会话库副本，旧运行时数据库保留以支持回退。

代理每次根据当前公开上下文核对请求，旧思考与旧工具私有文本不进入下一任务。压缩请求同样受范围核对：缺少当前标识时使用本任务最近已核对上下文或公开种子；只有本任务实际发起过压缩才接纳其摘要，剔除前一任务的旧私有摘要。详见 `desktop/agent-proxy.ts` 的 `createWireTaskScope` 和 `desktop/agent-context.test.ts`。

## 缓存、压缩与续办

- 供应商缓存是请求配置及用量报告；允许缓存不等于实际命中，也不等于永不过期。界面区分缓存读取统计、会话保留与复用。
- 自动压缩用于控制上下文；本机原文与用户确认仍按原存储职责保留，不把问题、模型建议或未回答选择写成已确认决定。
- 额外计费的定时缓存预热未开启，不提供“免费保温”的保证。
- 任务进度在 `engine/outputs/task-progress.json`，检查点与恢复文件索引在同一受管输出区；操作记录在 `engine/operation-journal.json`。这些是任务文件，不是全案共享缓存。
- 继续任务重新核对原输入、版本、文件摘要与操作结果；编辑、重试和新分支不无声继承旧分支产物。结果不明操作不自动重放，自定义 MCP 不在恢复时自动重放。

## 自动更新的实际边界

应用 0.22.0 捆绑的运行时快照为 OpenCode 2.0.27，版本与文件摘要见 `.lab/agent-runtime/runtime-manifest.json` 及包内同名清单。

`RuntimeManager` 默认自动检查：启动时一次，运行期间每 6 小时一次。候选从受支持的官方分发元数据下载，校验 SHA512 / SHA256 后运行四协议合成检查，包含工具、停止、保留会话、跨案隔离、强制压缩与旧摘要排除。任务仍在运行时仅保留候选，空闲后才激活；失败保持当前运行时，有上一可用版本时可回退。

兼容性由实际 API / 行为检查决定，不能只替换二进制，也不固化某个补丁版本。设置 → 应用与更新 → OpenCode 后台提供自动检查开关、立即检查、版本状态和回退。该页面每 2 秒读取状态不等于每 2 秒检查更新。

应用本身仍通过 .pkg / .exe 安装包更新。开发验证可通过 `PATENT_AGENT_DISABLE_RUNTIME_UPDATE=1` 停止本次进程的自动检查；这不是产品默认设置。
