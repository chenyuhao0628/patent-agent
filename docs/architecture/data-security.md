# 领域记录、持久化与安全

> 当前技术参考；需求以 [需求索引](../../REQUIREMENTS.md) 及其模块细则为准，状态与待办见 [实施计划](../../EXEC_PLAN.md)。代码路径相对仓库根目录。

## 6. 数据、文件和安全

### 6.1 案件领域记录

`src/domain/case-record.ts` 定义案件领域记录：

| 记录 | 管理内容 |
| --- | --- |
| `identity` | 案件身份与基础信息 |
| `stage` | 唯一当前阶段及各轮次阶段，不嵌入正文或材料 |
| `materials` | 公共材料、轮次材料及引用关联 |
| `manuscripts` | 正文、版本、讨论、复核、任务和定稿 |
| `outcome` | 官方结论与结案信息 |
| `transfer` | 远程流程、流转表单、回执与记录 |
| `storage` | 本机存储定位 |

旧 `Case` 由领域字段组合，是同步、文件与 IPC 的兼容表示。`DesktopService.workspace.cases` 仍保留为内存协调快照，不作为业务模块的数据接口。

业务模块分别使用 `CaseReplyView`、`CaseProfessionalView`、`CaseTransferModuleView`。写入通过主进程适配，不能将完整案件库或无关字段交给业务模块与模型。

### 6.2 持久化与迁移

- 账号私有 `workspace.json` 以带 schema、profile 和 SHA-256 的 `caseRecords` 为主记录，保留旧兼容表示。
- 迁移先备份原始字节，转换保留未知字段；损坏、摘要错误、账号不符或兼容数据冲突时阻止写入。
- 共享索引使用 schema 3，兼容 schema 1/2；领域索引与兼容索引必须一致。
- 共享目录只包含共享业务元数据，不包含本机私有对话、任务、凭证和扩展配置。
- 共享读取保留本机旧轮次、未列入共享清单的材料、关联和解析摘录；被替换稿件保留历史版本。
- 重复材料或版本身份、同 ID 不同路径等冲突不能静默覆盖。
- 业务材料中公共副本与当前轮次同 ID 时，答复和专业工作流均优先当前轮次；专业页面再次进入不恢复上次材料勾选，历史任务选材记录仍保留。

### 6.3 文件保护

文件身份应明确账号、案件、流程、轮次、角色、版本、时间、来源、内容哈希及用户确认状态。

原件只读，导入和下载保存副本；受控路径拒绝符号链接和目录穿越。写入使用临时文件、校验与原子替换；账号、目录或案件阶段变化后，拒绝迟到发布。

外部修改保留成果并标记 `externallyModified`。流转候选文件按案件归属、精确身份、哈希、类型与大小核验，不能以模糊名称匹配代替。

### 6.4 凭证、授权与工具

- 记住登录时，密码与模型 Key 经系统加密保存；凭证不得进入前端回显、普通日志、模型上下文或 Git。
- 登录、退出、关闭会中止在途自动重授权；账号切换清缓存并增加代际。
- 401 自动重授权只重试幂等读取；远端新增、修改、删除、转交和上传不自动重试。
- 任意命令和下载默认关闭，联网检索默认开启；本地 MCP 需开启相应命令权限，扩展不能改变案件隔离。
- 命令审计保存在任务目录的 `tool-audit`，诊断日志只记录必要元数据。
- 真实贝思兰德写操作必须有当前任务授权；接入文档本身不构成执行授权。
