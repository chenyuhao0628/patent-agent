| Agent 初始状态写入失败占用活动槽 | 先持久化后注册活动任务；模拟磁盘失败后重试成功 |
| 撰写页重进自动恢复上次选材 | 移除自动恢复，仍保留历史选材记录；源码核对及构建通过，原生交互待验 |
| 专业任务同 ID 材料使用旧公共副本 | 主进程与页面投影均优先当前轮次；新增双投影回归 |
