# 模型、Agent 与扩展工具

> 已确认需求；由根目录 [REQUIREMENTS.md](../../REQUIREMENTS.md) 索引。实现归档不使需求失效，本文不单独声明实现或验收完成。

## Agent 与模型

- Agent 只读取当前案件的冻结材料
- Agent 按权限使用本地工具
- Agent 写入受控产物目录
- 运行器使用随安装包提供的 OpenCode
- 没有捆绑运行器时不能启动 Agent
- 模型由设置决定
- 协议由设置决定
- 思考等级由设置决定
- 输出限制由设置决定
- 产品不锁定为某一个模型
- 设置按供应商组织模型
- 可以设置自定义地址、密钥、协议、上下文、最大输出和思考等级
- 可以获取上游模型列表
- 按会话使用所选协议要求的请求头
- 任务支持排队
- 任务支持停止
- 任务支持恢复
- 任务支持重试
- 任务支持分支
- 任务支持思考展示
- 任务支持分项保存
- 分项保存只接受预定字段
- 数组字段整段替换
- 嵌套对象整段替换
- 未通过校验的产物只保留为本次检查点
- 未通过校验的产物不覆盖上一份有效产物
- 完成检查未通过时在同一会话继续修复
- 连续两次没有新进展时停止自动修复
- 自动修复受任务时限约束
- 默认任务时限为 60 分钟
- 正式任务必须有真实读取证据
- 失败的任务不推进业务状态
- 停止的任务不推进业务状态
- 不完整产物不推进业务状态
- 模型不调用贝思兰德接口
- 贝思兰德请求由主进程发起
- 不把整个案件库交给模型
- 不把密钥交给模型
- 不把无关路径交给模型
- 模型上下文不跨案件混用
- 原生 shell 读写默认关闭
- 命令执行使用可停止、可记录的 `execute_command`
- 准备材料使用 `prepare_material`
- 阅读命令结果使用 `read_work_file`
- 最终结构化结果使用 `write_artifact`

## 工具、技能与对比文件

- 联网检索默认开启
- 联网检索可以关闭
- 软件下载默认关闭
- 任意命令默认关闭
- 预设转换组件自动安装可以单独开关
- 修改工具权限前先停止任务
- 工具权限为本机设置
- 任意命令以当前用户权限运行
- 任意命令可以联网
- 任意命令可以访问其他路径
- 任意命令不是文件沙箱
- 任意命令不是网络沙箱
- 任意命令的联网不受检索开关限制
- 任意命令的联网不受下载开关限制
- 应用不向命令环境传递凭证
- 应用不向命令环境传递整个案件库
- `download_file` 只在下载开关开启时可用
- `download_file` 接受公开软件地址
- `download_file` 单文件不超过 2GiB
- `download_file` 可以核对预期 SHA-256
- `download_file` 不自动运行所下载文件
- `web_search` 和 `web_fetch` 查询公开网页
- `web_search` 和 `web_fetch` 保留来源
- `web_search` 和 `web_fetch` 不携带账号凭证
- 外部网页内容不作为操作指令
- `web_fetch` 不读取本机或内网地址
- 命令、退出码和限长输出写入 `tool-audit`
- 停止任务时结束该任务启动的命令进程
- 独立启动的图形程序不要求随任务关闭
- Mac 可用系统 `textutil` 读取普通旧 DOC
- LibreOffice 是可选组件
- LibreOffice 不进入主安装包
- 旧 DOC 优先由内置阅读转换
- 不把命令行 LibreOffice 作为默认转换方式
- 扫描 PDF 提供页图
- 工具目录在 Mac 为 `~/Library/Application Support/专利工作台/tools/`
- 工具目录在 Windows 为 `%APPDATA%\专利工作台\tools\`
- 下载文件和应用更新后保留自装工具
- 单次命令的临时文件留在该任务目录
- 单次命令的临时文件不进入原始申请库
- 可以导入含 `SKILL.md` 的技能文件夹
- 可以编写技能
- 可以粘贴 MCP 配置
- 可以启停、编辑、删除和测试技能或 MCP
- 远程 MCP 支持地址和 headers
- 本地 MCP 支持 command、args、env
- 不包含 OAuth 交互登录
- 不包含技能二进制资产导入
- 扩展在下一次 Agent 任务生效
- 本地 MCP 要求已开启任意命令
- MCP 不是案件沙箱
- Header 和 env 中的凭证加密保存
- 编辑凭证时显示占位符
- 编辑凭证时不显示原秘密
- 技能和 MCP 是本机配置
- 技能和 MCP 不随案件目录迁移
- 扩展不改变案件、凭证和上下文隔离
- 通知由贝思兰德同步获得
- 不另做批量通知导入
- 从当前通知识别公开号
- 通过智慧芽把 PDF 下载到当前轮次
- 已下载的对比文件复用
- 对比文件失败时显示原因
- 可以重试对比文件下载
- 可以手工补充公开号
- 向智慧芽只发送公开号
- 智慧芽凭证按账号加密保存
- 扫描页不能视为已识别完成
- 公开号不完整时不能视为已识别完成
- 非专利文献不能视为已识别完成
- 可以导出最近 10 分钟诊断日志
- Windows 主窗口不显示「专利工作台 / 帮助 / 编辑 / 窗口」原生菜单栏，也不通过 Alt 重新显示；诊断日志仍由应用内设置导出，macOS 系统菜单保留
- 诊断日志只保存在本机
- 诊断日志不自动上传
- 诊断日志不保存密钥
- 诊断日志不保存请求和响应正文
- 诊断日志不保存案件正文
- 诊断日志不保存文件名和完整路径
- 诊断日志最多 5 个文件
- 每个诊断日志文件最多 1MiB
