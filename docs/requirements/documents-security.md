# 文档、目录、账号与安全

> 已确认需求；由根目录 [REQUIREMENTS.md](../../REQUIREMENTS.md) 索引。实现归档不使需求失效，本文不单独声明实现或验收完成。

## Word 与公式

- 申请文件导出使用 `resources/document-templates/application.docx`
- 答复文件导出使用 `resources/document-templates/reply.docx`
- 导出前核对模板摘要
- 适配模板前读取该模板文件
- 未做版式验证时，不把模板导出视为已验收
- 行内公式使用 `$...$`
- 独立公式使用 `$$...$$`
- 界面使用离线 KaTeX
- 导出 Word 时把 LaTeX 转为可编辑公式
- 从 DOCX 读取时保留公式
- 无损语义往返支持：分式、根式、上下标、n 元运算符（∑∏∫ 等 14 种）、重音（overline/vec/hat 等）、上下极限、矩阵与括号内容（2026-10-01 公式缺陷修复后确认）
- 其余未知公式结构仍按“无法无损表达即拒绝载入”失败关闭，不以文字占位代替
- 已验证的自动填充范围是正文、中文字体、分节页眉页脚和跨页排版
- 附图使用经核对的 Word 文件
- 复杂公式使用经核对的 Word 文件
- 不用文字占位代替附图
- 不用文字占位代替复杂公式

## 文件与目录

- 原始申请库单独保存
- 共享工作目录单独保存
- 本机对话单独保存
- 凭证单独保存
- 原始申请库与总工作文件夹不能是同一目录
- 原始申请库不能位于总工作文件夹内
- 系统生成的案件目录名称为客户名称、专利名称、专利类型
- 业务目录区分撰写、答复审查意见、答复补正
- 目录名不使用时间
- 必要时保留机器标识
- 整理只处理当前账号可确认归属的系统生成内容
- 整理不修改未知目录
- 整理不修改冲突项
- 整理不修改符号链接
- 整理不修改用户文件
- 整理期间暂停同步
- 整理期间暂停模型任务
- 整理期间暂停其他文件写入
- 整理完成后更新索引和相对路径
- 整理不删除文件内容
- 同步不删除文件内容
- 整理不覆盖文件内容
- 同步不覆盖原件
- 迁移先预览
- 迁移经过复制和校验后才切换目录
- 迁移不移动原始申请库
- 迁移保留旧工作目录
- 支持跨设备读取共享工作目录
- 案件目录内的符号链接被拒绝
- 路径穿越被拒绝
- 跨账号材料被拒绝

## 账号与安全

- 登录按账号隔离
- 账号切换按账号隔离
- 凭证按账号隔离
- 模型配置按账号隔离
- 案件目录按账号隔离
- 勾选记住登录时，密码和 Token 由系统加密保存在本机
- 记住登录时，Token 失效可自动换取新 Token；幂等读取单次透明重试，上传、保存、删除和转交不自动重放
- 多个并发请求遇 Token 失效时合并为单次重授权，避免并发重登
- 不勾选记住登录时不保存密码
- 模型密钥由系统加密保存
- 已保存的凭证不从主进程回显到渲染进程；用户在登录 / 模型设置中主动输入的秘密经受控 IPC 交主进程保存
- 凭证不进入普通日志
- 凭证不进入 Git
- 渲染进程不直接访问磁盘
- 渲染进程不直接执行同步
- 渲染进程不直接读取密钥
- 渲染进程不直接执行命令
- Electron 使用隔离上下文
- Electron 关闭 Node 集成
- Electron 只暴露有限 IPC
- 外部响应按明确契约校验
- 未知业务结果不是成功
- 账号切换后的迟到任务结果被拒绝
- 未授权时不读取真实凭证
- 未授权时不执行真实业务写操作
- 不覆盖用户已有改动
- 未授权时不提交
- 未授权时不推送
- 未授权时不发布
- 未授权时不覆盖现有安装
