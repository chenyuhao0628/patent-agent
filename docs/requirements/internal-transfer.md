# 提交与内部转交

> 已确认需求；由根目录 [REQUIREMENTS.md](../../REQUIREMENTS.md) 索引。实现归档不使需求失效，本文不单独声明实现或验收完成。

## 提交与内部转交

- 提交是案件中的独立页面
- 提交页位于贝思兰德流程之后
- 可内部转交时才显示启动递交
- 启动递交进入提交页
- 启动递交不提交官方
- 启动递交不转交下一办理人
- 待处理且尚无递交实例时才可启动递交
- 启动失败可以重试
- 他人正在办理时拒绝启动
- 启动成功后才进入待核对
- 程序准备材料勾选和表单
- 用户核对后才保存
- 保存后回读
- 保存、内部转交、官方递交分别显示
- 本地保存不是官方递交成功
- HTTP 成功不是官方递交成功
- 内部转交成功不是官方递交成功
- 保存分多步写入服务端
- 保存中断后以回读为准
- 保存中断后不自动重发转交
- 转交前校验远端材料和表单完整
- 已转交的同一提交不能重复转交
- 提交状态包含草稿
- 提交状态包含已保存
- 提交状态包含待核对
- 提交状态包含已转交
- 被替换的旧方案保留
- 被替换的旧方案不能再执行
- 已保存或待核对可以撤销保存
- 撤销保存回到草稿
- 撤销保存保留表单、补正、文件副本和接收人
- 撤销保存后，远端已有文件不自动恢复为已保存
- 再次保存成功后才允许远端状态恢复为已保存
- 草稿可以移除单份本地材料
- 有当前节点编辑权限并经确认后，可以删除远端已上传材料
- 2026-09-29 确认：远端材料列表支持单份文件删除，草稿和已保存状态都提供直接入口，不要求先撤销保存；整组清理作为独立操作，不得用整组清理代替单份删除
- 单份删除按当前递交实例、不可变 FileNo 及明确表单关联核验；同名不猜测，关联不唯一或接口不支持的材料不得扩大删除范围，并说明原因
- 删除确认明确显示案件、流程、文件和影响范围：移除当前递交实例的远端文件关联，保留其他远端材料、本地原件与草稿，不宣称服务器底层文件永久删除
- 删除前回读确认身份、版本与编辑权限，删除后回读确认目标消失；中断或结果未知时保留待核验记录，禁止继续转交或自动重复删除，重开后可刷新核对
- 材料区域统一文件行、图标、间距、按钮高度与对齐方式；单份删除、整组清理、本地移除和返回编辑使用不同且准确的提示，并验证桌面与窄屏布局
- 删除远端材料不是官方递交
- 保存后可以预览正文和公式
- 文档与材料预览支持提取和显示 DOCX 内嵌附图及独立图片（PNG/JPG/WebP/BMP/SVG）
- 《说明书附图》和《摘要附图》在纯图或无文本正文时完整提取附图序列呈现，不显示为空或无正文
- 预览组件支持图文混排与 KaTeX 公式共存，支持大图全屏弹窗查看与视口滚动保护
- 本机没有文件时可以下载远端文件预览
- 其他已登录设备可以识别远端已保存材料并转交
- 其他设备转交不要求本机重新上传同一文件
- 下一节点用户标识明确且不同时，不视为转交成功
- 下一节点用户标识为全零时，按办理人姓名核对
- 官方结论已到时不能内部转交
- 已提交官方后不重复提交
- 转交申请文件名称与系统名称差异确认采用应用内统一弹窗交互，避免系统原生弹窗
- 提交页可以改用本地文件
- 草稿状态下可以选择文件
- 工作台稿件不可用时不阻断本地文件提交
- 使用工作台稿件时取当前策略下的最新可用稿
- 工作台稿件生成案件内提交副本
- 勾选确认后才允许保存工作台稿件
- 准备提交不自动采用工作稿
- 准备提交不自动覆盖工作稿
- 准备提交不自动启动、保存或转交
- 修改前的申请文件只用于比对
- 修改前的申请文件不上传
- 有修改时才提供修改后的申请文件
- 意见陈述书是答复正文
- 答复和补正只要求本次勾选部分解析成功
- 提出申请要求完整五书
- 指定摘要附图默认为 1
- 指定摘要附图可以修改
- 指定摘要附图写入说明书附图
- 需要案件名称时使用本次解析出的说明书名称
- 案件名称保存后回读核对
- 提交页带入已采用稿的修改部分
- 提交页预选对应材料清单
- 内部流转按当前可办理的贝思兰德流程显示
- 内部流转不依赖旧的本地定稿字段
- 贝思兰德节点显示在流程页
- 转交操作位于提交页
- 核验转交结果包括案件、流程、接收人和服务端业务结果
- 内部转交的默认下一办理人为杨佳（UI 默认值，可按实际流程改选；实现见 `src/components/InternalTransfer.tsx`、`src/components/CaseSpace.tsx`、`src/domain/workflow-nodes.ts`）

## 2026-09-29 实测修复补充要求

- 已关联贝思兰德案件使用本地 Word 可独立完成保存和转交，不依赖 AI 稿件
- 下一办理人只能取服务端当前候选；优先保留有效人工选择，否则在候选唯一匹配时默认杨佳，不能虚构用户 ID
- 远端同一递交实例已有完整申请文件、五书和对应表单时，无须再提供本次本地文件或重复上传
- 远端有文件不等于材料完整；缺项提示具体指出文件、表单、设置或权限问题

## 2026-09-29 单文件删除与材料界面补充要求

- 内部流转支持单个远端文件关联删除；草稿及已保存、尚未转交的可编辑方案均有入口
- 按确切文件编号、递交实例和材料版本确认删除，不按名称猜测或扩展成整组删除
- 单份删除保留其他远端材料、业务表单、本地原件和历史；成功后重新核对并保存
- 删除按钮与确认框明确作用范围；本地「取消选择」、远端「删除关联」及「清理整组材料与表单」分开命名
- 缺少唯一安全表单关联或权限的文件说明不可删除原因；不以整组清理兜底
- 删除中断后保留待核验状态，重开仅核验，不自动重发
- 远端、本地、预览选择与核对清单使用一致的材料行、图标、间距、按钮样式；长文件名可换行，同类操作列对齐，窄屏无页面横向溢出
