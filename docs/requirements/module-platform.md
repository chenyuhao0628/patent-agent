# 模块平台与统一数据管理

2026-10-12 用户明确授权：完整规划与复核后，实现面板注册与宿主、统一数据管理、可替换适配器和模块接入模板，分阶段检查并本地提交，最终阶段完成后结束目标。

- 新模块复用统一导航、路由、能力 / 访问判断和宿主生命周期，减少新增业务页面时分散修改壳层。
- 案件数据使用统一身份、权威记录、读取和受控写入；继续隔离账号、案件、阶段、分支与版本。共享材料、任务 / 对话及凭证按既有边界保存。
- 引擎、外部业务系统和存储有明确适配合同及装配入口，以实际可替换测试验证，不把类型接口等同于真实供应商支持。
- 模块接入模板须可生成、注册、构建和加载；新增后台写入 / 长任务仍需相应合同及校验。
- 保留既有案件、答复、撰写、独立审查与内部流转语义；只读面板不自动开始办理。旧 URL、历史记录和用户稿件保留。
- 本次授权包含本地实现、回归、打包及逐阶段本地提交，不包含推送、发行发布、覆盖安装或真实生产业务写入。

实施范围、步骤及实施前复核见 [模块平台方案](../design/module-platform.md)，当前进度只维护于 [EXEC_PLAN.md](../../EXEC_PLAN.md)。
