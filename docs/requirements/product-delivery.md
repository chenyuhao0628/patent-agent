# 产品与交付

> 已确认需求；由根目录 [REQUIREMENTS.md](../../REQUIREMENTS.md) 索引。实现归档不使需求失效，本文不单独声明实现或验收完成。

## 产品

- 独立桌面专利工作台
- 以案件为中心管理材料、任务、对话、稿件和成果
- 范围包含案件管理
- 范围包含贝思兰德个人案件只读同步
- 范围包含审查意见答复
- 范围包含补正
- 范围包含从技术交底开始的专利撰写
- 范围包含用户自己的独立稿件审查
- 范围包含贝思兰德表单保存
- 范围包含贝思兰德内部转交
- 答复是完整交付重点
- 撰写、独立审查、内部业务写入属于产品范围
- 产品不收成只有答复
- 应用拥有案件界面和业务流程
- 后台 Agent 通过结构化接口接入
- 导入、整理、下载与模型分析分开
- 不凭终端文本判断运行状态
- 交付物是可安装、可双击启动的 macOS `.app`
- 交付物包含 Windows `.exe`
- 浏览器原型不能代替桌面启动、落盘、退出恢复和安装验收
- 独立安装不要求配置旧仓库源码路径
- 不修改 `patent` 来源仓库
- 不修改 DSH 来源仓库
- 不修改 `0001` 的代码和运行环境
- `0001` 接入文档只作接口参考
- 接入文档中的写操作不构成执行真实提交的授权

## 版本与验收口径

- 版本为主版本.功能版本.修复版本
- 不兼容变化增加第一位，后两位归零
- 新增功能增加第二位，第三位归零
- 兼容修复增加第三位
- 只修改文档不升级安装版本
- 当前源码与安装版本以 package.json、锁文件、README、实施计划及实际安装清单为准；历史版本数量不是当前目录的保证
- `package.json`、锁文件、README、实施计划和安装清单使用同一版本
- 每个安装产物带版本和平台
- 版本和摘要以 `release/release-manifest.json` 为准
- 构建失败时保留上一版安装包
- 当前安装包不包含发行签名
- 当前安装包不包含 macOS 公证
- 整体应用通过安装包更新；OpenCode 后台按 2026-10-12 确认要求自动检查并安装兼容更新
- 自动化通过只表示合成或隔离场景通过
- 构建完成只表示安装包可以生成
- 真实模型质量须有单独证据
- Windows 实机须有单独证据
- macOS 安装须有对应当前版本的单独证据
- 真实业务写入须有单独证据
- 复杂图形须有单独证据
- 签名、公证、自动更新、云盘协作须有单独证据
- 已有证据文件保留原文件名和原编号
- 版本号增加不等于未验收项已经完成
