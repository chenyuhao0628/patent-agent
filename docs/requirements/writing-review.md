# 撰写与独立审查

> 已确认需求；由根目录 [REQUIREMENTS.md](../../REQUIREMENTS.md) 索引。实现归档不使需求失效，本文不单独声明实现或验收完成。

## 撰写

- 撰写阶段为方向构思
- 撰写阶段为技术方案与保护架构
- 撰写阶段为说明书
- 撰写阶段为权利要求书
- 撰写阶段为申请文件整理
- 撰写包含上述五类步骤，但不要求所有案件都从方向构思开始；根据已有材料由用户选择起点，缺少的步骤再补
- 起点之前未执行的步骤不伪装为已确认；已提供的材料与用户确认分别标注
- 每个实际生成并采用的撰写步骤单独确认
- 同一步骤旧完成稿可明确选择后采用，新修改任务保留独立进度和续办记录；正文、依据与进度须对应明确任务 / 版本
- 退回修改后，旧上下文完成稿仍可明确采用；采用须二次确认，并按当前上下文生成本步骤新记录，原任务记录保留（2026-10-01 确认）
- 退回修改前序步骤时保留所有历史成果，后续旧结果不自动当作新上下文下的当前结果
- 阶段结果正文（含方向构思、已保存 Word 预览和生成中的文字）在独立内容区滚动，确认输入与按钮紧邻正文，不随长内容推到整页末尾
- 左侧本阶段输入与参考材料共用一个滚动区，参考材料列表不再嵌套第二条滚动条；生成与阶段历史按钮保留在滚动区外
- 阶段正文宽度随窗口自适应拉宽，保留两侧留白；左侧输入区内容留出小幅边距，滚动条靠区域外沿且不贴住文字
- 窗口允许适度整页滚动，优先保证正文可读性；按 13 英寸 MacBook 的 1280×800、1440×900 逻辑视口及 24 英寸 1920×1080 显示器检查，不以缩小正文高度换取全部内容塞进一屏
- 撰写使用随应用提供的 draft 标准技能
- 没有参考文件时可以输入文字构思
- 参考材料从本机复制到 `01_通知与材料/撰写参考/`
- 参考材料原件保留
- 同名参考材料分开保存
- 参考材料支持 DOCX、DOC、PDF、TXT、Markdown、PNG、JPEG
- 每次参考材料 1 至 12 份
- 每份参考材料不超过 20MB
- 新添加的参考材料自动勾选
- 可以取消勾选
- 离开页面后再次进入须重新选择本次材料
- 只有本次勾选的材料进入冻结副本
- 打开查看使用本机默认应用打开案件副本
- 移出列表只取消手动参考材料的列表关联
- 移出列表保留磁盘副本
- 移出列表保留历史任务输入
- 同步通知不能在参考材料列表中移除
- 原始申请不能在参考材料列表中移除
- 添加成功不等于解析成功
- 任务运行中不能改参考材料
- 阶段不可编辑时不能改参考材料
- 案件同步中不能改参考材料
- 取消系统选文件不添加材料
- 参考材料导入不向贝思兰德上传
- 勾选的撰写材料落盘

## 审查

- 独立审查可选
- 独立审查不阻塞定稿
- 独立审查不阻塞提交
- 缺少审查报告不阻止定稿
- 审查报告过时不阻止定稿
- 存在未处理审查问题不阻止定稿
- 审查报告保留
- 审查问题保留
- 历史审查版本保留
- 审查使用独立上下文
- 审查绑定指定稿件版本
- 修改正文后旧复核失效
- 审查使用随应用提供的 review 标准技能
- 侧栏「审查」汇总全部审查记录
- 审查次数按实际执行次数计算
- 审查默认展示待审稿件
- 独立复核不要求并行多个子代理

## 2026-09-29 实测修复补充要求

- 撰写阶段成果（含方向构思）生成真实 DOCX，页面按确切成果文件预览；不是把 Markdown 原文冒充 Word
- Markdown 原始阶段结果和旧历史保留；标题、加粗、列表、表格、公式在阶段文档中按语义呈现
- DOCX 生成或读取失败显式报告，不以旧文本、错误版本或隐藏符号代替成功
- 阶段文档沿用现有已指定模板资源并核验；不改变正式申请五书模板与确认流程
