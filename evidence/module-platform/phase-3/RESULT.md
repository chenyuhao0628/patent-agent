# 阶段 3：面板注册与宿主

2026-10-12。全局页面、案件标签、导航 / 页名和加载入口从 panels 注册表派生。PanelHost 管理访问能力、未知入口、只读数据接口、延迟加载、局部失败重试和账号 / 案件 / 阶段 / 历史目标的组件生命周期。CaseSpace 保留案件壳层及已有管理操作，业务组件装配移入模块适配器。新增模块只需要独立组件和描述，统一注册在 custom.ts。
