# 模块平台最终交付：0.22.0

2026-10-12，分支 codex/module-platform，基线 6f31104。六阶段均已实施、检查并分阶段本地提交。最终版本由本阶段提交承载，不推送或对外发布。

## 实现

- 全局工作区与单案入口分别注册，共用校验 / 宿主。内置页面全部通过面板定义装配，模块 ID 不改变业务当前阶段；新增模块无须在 App、PageContent、CaseSpace 增加分发。
- 主进程权威仓储、渲染层统一 Store 与作用域数据接口；原格式、未知字段、迁移备份、损坏保护和有序保存保留。模板默认只读，卸载和账号 / 案件 / 阶段变更使旧接口失效。
- 引擎、业务客户端、存储具备合同 / 能力检查及实际工厂入口。生产适配器和独立测试替代实现通过合同验证；生产仍是 OpenCode、贝思兰德及本机文件。
- 全局 / 单案模块模板及生成器真实生成、注册、构建、原生加载通过；相同功能可分别接入两处，重复生成及不安全路径拒绝。
- 性能实测暴露的懒加载额外等待和初始多案目录并发失败均修复。
