日期：2026-10-12；应用仍为 0.20.1，OpenCode v1 接口暂时保留供迁移前对照。

- F1：结束必须同时满足最终 assistant、无待完成工具及当次成功轮询 idle。tool-calls / unknown 回合与 busy 状态不能作为完成；新增真实 HTTP + MCP 场景先写中间稿，再写核对后的最终稿。
- F2：取消在每次异步资源创建后检查，清理跟踪实际创建的资源，可再次等待；预先取消与 broker 初始化中取消均无残留监听服务。
- F3：Fetch 已解压正文不再携带压缩头和旧长度；Node 路径先解压 gzip / deflate / br，再执行 DeepSeek 事件转换，按解压后的字节数限制响应。
- F4：后台 exit / error 触发终止，返回 server_exited / process_error；消息超限不继续轮询到总时限。
- F5：响应未正常写完时 close 向上游传播取消；回归在 POST 已完成且读到首段 SSE 后取消，核对上游响应连接确实关闭。
- F6：POSIX 清理整个受管进程组，即使父进程已退出。Windows 使用 Job Object 托管后代，并在 CreateProcess 时原子加入；退出 / 强制结束 supervisor 均关闭作业。工作命令也使用同一托管路径。
