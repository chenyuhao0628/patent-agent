## 环境与范围

- 使用既有 `0.15.0` 生产前端资源，资源 SHA-256 见 [artifact-hashes.json](artifact-hashes.json)。没有修改业务源码，没有重新打包安装程序。
- 通过 browser-skill 的独立 Agent Window（会话 `sscy`）操作真实 Chrome 页面，按快照定位按钮，并逐张读取截图进行目视核验。
- `127.0.0.1:4175/?qa=1`：生产构建原有浏览器示例案件库。
- `127.0.0.1:4176/pr8-visual?qa=1`：同一生产前端资源，加载 [synthetic-server.mjs](synthetic-server.mjs) 提供的纯内存桌面接口。界面可能显示“桌面版”，但这不是 Electron 原生运行验收。
- 合成案件 QA-VISUAL-1 / QA-VISUAL-2；未加载真实账号、凭证、案件或服务端数据。合成服务器 CSP 限制外部连接，接口不执行真实业务网络调用或案件文件写入。
- 桌面窗口宽 1440 CSS px，可用内容宽约 1425px；手机模拟 390×844、DPR 1。窄屏标签栏为自身横向滚动，不是页面整体溢出。
