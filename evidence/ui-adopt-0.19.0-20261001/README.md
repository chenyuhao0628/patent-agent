# 2026-10-01 撰写“退回前完成稿显式采用”UI 视觉验证（0.19.0，M4）

环境：真实 `ProfessionalWork` 组件 + 合成案件与合成 API（复用 [../ui-polish-20260930/](../ui-polish-20260930/) 脚手架），bsk 浏览器自动化，CDP 精确 CSS 视口模拟（DPR 2）。与两台物理设备的真实验收分开，不替代后者。

## 验证路径与结果

1. 撰写页（当前步骤“申请文件整理”，含较早上下文“权利要求书”完成稿）→ 点击产品按钮“返回补充 / 修改”（目标默认“权利要求书”）。
2. “选择本步骤成果版本”下拉出现 **“退回前版本 1 · 采用需再次确认”**；选择后显示提示“这是退回修改前的旧上下文完成稿。确认采用会按当前要求生成本步骤记录并保留原任务记录……”。
3. 点击“确认采用此版本，继续下一步骤”→ 弹出**二次确认**对话框“再次确认：采用退回前的完成稿”（含取消 / 确认采用此版本）。
   - 取消路径：对话框关闭，不发送任何命令（lastCall 仍为 restart）。
   - 确认路径：发送 `{type:'confirm',jobId:'completed-write',decision:'',adoptEarlier:true}`，步骤推进（“权利要求书 已确认 / 申请文件整理 当前步骤”）。
4. 布局：1440×900、1920×1080、1280×800 三个精确 CSS 视口下 `overflowX no`（页面文本测量浮层直读）；弹窗在三视口均完整可见。
5. 控制台：无产品错误（仅浏览器扩展与 React DevTools 提示）。答复 / 补正 / 等待官方页面同视口 quick check 无横向溢出。
