# 应用图标

定稿方向：年轻、浅色、淡紫点缀，与工作台 UI 相似；圆角浅紫底，白色折角文档、紫色笔尖和三点。无深色厚重底板，不添加文字。

- `icon.png`：imagegen 内置模式生成的浅色定稿，原始绘制内容保留，用于 macOS 和界面。源生成文件为 `exec-afd46ec6-3346-4a8b-88fe-7d8f1f9c90d6.png`。
- `windows.ico`：Windows 打包专用，16 / 24 / 32 / 48 / 64 / 128 / 256 共七档，32 位颜色与透明圆角。
- `windows.png`：Windows 图标透明轮廓母版。

图片工具的透明背景编辑仍返回 RGB 棋盘格，未采用该结果。Windows 图标编码保留已选图案，裁出浅紫图标主体，并应用圆角透明外轮廓；源图 `icon.png` 不改动。实际从 Windows 安装器提取主 EXE，七档 ICO 图像均与资源中的透明 PNG 数据匹配；未以源文件存在代替打包结果核验。
