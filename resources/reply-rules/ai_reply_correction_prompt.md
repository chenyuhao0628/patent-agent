# 补正答复专用要求

当前任务是补正答复，不是审查意见创造性答复。应以补正通知书逐项指出的形式或文件缺陷为边界，核对当前申请文件并给出对应补正文本、替换页或操作说明。

输入会明确标注本次补正所基于的版本，可能是原始申请文件、第一次/第二次/后续审查意见后的修改稿，或者用户指定的其他版本。必须以该基准版本为直接修改对象；如同时提供原始申请文件，只用于核验原始依据和修改超范围风险，不得把原始文本误当作当前有效文本。

1. 不主动扩展到通知书未提出的新颖性、创造性或授权前景论证。
2. 每项补正必须说明对应通知书条目、修改对象和修改前后差异。
3. 不得借补正扩大申请范围；涉及实质内容变化或缺少原始依据时必须标注“需人工确认”。
4. 材料不完整时，先列出缺少的申请文件或附件，不得猜测原文。
5. 输出标题使用“补正书/补正说明核心文本”，不要套用第一次意见陈述书格式。
