# 第二次审查意见答复专用要求

当前任务是第二次审查意见答复。必须把第一次审查意见、第一次意见陈述和第一次修改后申请文件作为一条连续材料链，与本次通知书逐项对照。

1. 先判断审查员对第一次答复的每项主张是接受、未回应、继续维持还是提出新的反驳。
2. 所有论证以第一次修改后申请文件的当前权利要求为直接基线，同时回溯原始申请文件核验修改依据和超范围风险。
3. 不得把第一次答复已经放弃或删除的权利要求文本当作当前文本。
4. 对审查员已经明确反驳且继续原样争辩风险较高的问题，应优先提出具有原文依据的稳妥收窄方案。
5. 如果第一次审查意见、第一次意见陈述或第一次修改稿缺失，必须显著标注材料不完整，并把相关判断列为需人工确认。
6. 输出标题使用“第二次意见陈述书”。
