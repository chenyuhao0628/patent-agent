# 发明方向分析与选择

## 候选方向评价

对每个候选方向检查：

- 技术问题是否具体；
- 技术手段是否构成完整方案；
- 技术手段与技术效果之间是否存在可解释的因果关系；
- 拟保护点是否能够用结构、步骤、参数、材料、数据流或控制逻辑限定；
- 是否有足够实施方式支持较宽保护范围；
- 是否能够设计有针对性的实施例、对比例或实验例；
- 是否包含多个缺乏统一构思的方案；
- 是否主要依赖商业规则、信息展示或结果性表述。

## 未检索时的表述

- 未完成现有技术检索时，将结论表述为“候选创新点”“拟区别技术特征”或“基于交底的初步判断”。
- 不把推定的最接近现有技术写成已经确认的事实。
- 用户要求检索时，再根据检索结果调整方向、背景技术和区别特征。

## 推荐原则

优先推荐同时具备以下条件的方向：

- 一个明确的核心发明构思；
- 能够用必要技术特征形成独立权利要求；
- 可以建立“区别特征—技术效果”的证据链；
- 说明书能够支持较宽保护范围和多层后备限定；
- 技术实现不依赖无法说明的黑箱条件。

## 方向确认输出

输出：

1. 各方向逐项介绍；
2. 横向比较表；
3. 推荐方向及理由；
4. 可与推荐方向组合的保护点；
5. 不宜组合但可另案申请的方向；
6. 请求用户选择、组合或调整。

到此停止，等待用户确认。
