# 工作流状态管理

每轮开始时读取上一轮状态卡，每轮结束时更新状态卡。状态卡是工作记录，不得混入正式申请文件。

## 固定阶段

1. 方向构思与确认；
2. 保护架构与确认；
3. 说明书撰写与确认；
4. 权利要求书撰写与确认；
5. 摘要及正式申请文件；
6. 最终复核与交付。

不得跳过前四个确认点。只有用户对当前阶段作出明确确认后才能进入下一阶段。

## 状态内容

使用 `assets/workflow-state-template.md` 记录：

- 当前阶段和版本；
- 已确认方向；
- 已锁定创新点；
- 已锁定术语；
- 已确认参数；
- 已选领域模块；
- 检索状态；
- 已完成文件；
- 待确认事项；
- 下一步。

## 更新规则

- 用户只确认部分内容时，保持当前阶段，标明已确认和未确认部分。
- 用户说“按推荐方案”“确认”“继续”等且语义明确时，视为确认当前阶段。
- 用户提出修改时，先更新状态卡，再按 `references/change-propagation.md` 分析影响。
- 不覆盖历史关键决定；版本号递增并在状态卡中简述变化。
- 同一术语出现多个候选名称时，在术语锁定前不得混用。
- 参数尚未确认但不影响当前阶段时，可标为“暂定”；进入正式申请文件前必须统一。
