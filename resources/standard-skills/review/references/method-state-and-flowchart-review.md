# 方法状态与流程图一致性审查

在申请包含方法权利要求、工艺步骤、控制流程或文字密集型流程图时读取。

## 一、建立步骤对照

使用`assets/method-step-crosswalk-template.csv`，逐项记录：

- 步骤编号；
- 权利要求表述；
- 说明书表述；
- 流程图表述；
- 步骤前状态；
- 步骤后状态；
- 前置条件；
- 对照状态。

不得仅比较S编号。步骤数量相同但动作对象、顺序、条件或结果不同，仍属于实质冲突。

## 二、状态迁移

对容器、介质、温度、压力、运动、载荷、采集和安全状态建立前后关系。重点检查：

- 开盖、装样、加液和密封的可执行顺序；
- 加压、升温、加载和采集的先后及保持条件；
- 泄压、冷却、停止运动、取样和开盖的安全顺序；
- 某步骤是否依赖尚未建立的状态；
- 同一动作是否被重复、遗漏或使用矛盾动词。

## 三、流程图生成和修改

- 以权利要求和说明书已经统一的步骤为依据；
- 方框使用概括性短语，不在图中增加新的条件或技术效果；
- 保持S编号、顺序、分支和循环与正文一致；
- 重绘后逐字核对中文、数字、箭头和图号；
- 若权利要求与说明书尚未统一，先解决文字冲突，不得用流程图替任一版本作选择。

`scripts/audit_method_step_alignment.py`只检查结构化对照表的编号连续性、栏目完整性和已声明冲突，不自动判断步骤语义等同。
